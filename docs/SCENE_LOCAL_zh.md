## 初始化与输入

按用户更新的训练顺序，v3 **直接从 AMASS EGO-only 验证最佳 50k 初始化**，SHA256 为 `0c30ba25dc42c568a8e2fcefae2e39a142930ff26d7a39bd7ff446eaf4e9710f`；不再从旧混训底座派生的场景 10k 初始化。验证选择已在 test 前固定。新原生体形、场景与局部路径随此分支适配，优化器重新建立。原全局场景分支继续独立运行作为历史对照；它本身也是 EGO-only 场景训练。

仍只用 EgoBody、TRUMANS、GRAIL 的 EGO 数据，训练和选模排除 RICH；128 帧、30 Hz、batch 8，计划 30k 更新。旧 scene10k 初始化的验收记录与代码保存于 `preparation_history/scene10k_preflight.zip`，明确为历史准备记录，不能用于当前版本开训。

输入只有相机、允许的标定和已观测场景。SMPL/SMPL-X 的个体系数与模板由输入预测；GRAIL 使用公开固定 G1 输出模板。局部皮肤锚点用这些预测参数及当前预测动作生成，不读取真实个人皮肤资产、rest 或 betas。训练标签只进入监督。

沿用窗口开始前及开始帧的因果静态观测前缀，最多 8,192 点；另取每帧实际可见表面，最多 512 点。目标人体点剔除，不将未来帧的静态并集用于当前查询。400 条坐下录制的完整椅子仅作为有独立来源标记的训练合成增强；验证不补椅子。

## 动作如何接受局部反馈

共享 denoiser 先产生无场景动作提案。用预测原生体形将提案转换成 67 个皮肤锚点，在每个时刻查询因果历史与该帧观测表面的近邻；将局部相对坐标、距离和有效性送入身体区域条件，再与全局/patch 条件共同生成动作。近邻上限 8，查询半径 0.6 m。没有真实观测时保留空查询，不将未知空间当作自由空间。

显式 root/rotation 修正同时要求 0.25 m 内真实表面支持及可学习接触/对应置信度；单次修正范数分别限于 4 cm、0.06 rad，并随噪声水平收敛。改旋转后重新 FK，保持骨长和位置通道一致。局部条件投影和显式反馈均从零初始化，首个输出与父模型逐位一致。独立开关允许后续用同一权重关闭整个局部路径或只关闭显式修正，检验收益与副作用。

当前点云缺少可靠法线和速度：相应特征为零且无效，不伪造表面法线或有符号穿透距离。没有新增完整网格碰撞损失，限幅和门控也不能保证零穿透。接触置信度目前由动作监督间接学习，不能称为已经准确的接触分类器。

## 后续效果判断

GRAIL 检查已获接受。v3 每 1000 更新保留候选并以约 176 个固定窗口筛选；训练结束以最多 1416 个窗口、覆盖全部 679 个验证家族，复核小集前三名与最终权重。DDIM 20、seed 777，主分数为三数据集等权 MPJPE，GRAIL 内五类动作等权、类内家族等权。小集最佳明确为临时结果，较大集复核完成后才公布最终选择。实际数量以冻结清单为准，候选权重保留供复核；该较大集是家族全覆盖，未遍历全部验证帧。验证不使用合成完整椅子，不因训练筛选删除难例，也不读取 test。详见[实验顺序与验证方案](EXPERIMENT_PLAN_zh.md)。

局部条件与显式修正须分别关闭比较，联合查看可观测表面的足底/座面接触、滑动、穿透和连续性。旧反馈消融没有显示稳定收益，新路径验收也只说明能正确运行；只有训练后指标及可视化才能说明是否改善坐下和踩台阶。

后续先保存 EGO-only 场景最佳权重，再从它派生 EGO+EXO 的统一适配。引入 EXO 时保留 EGO 数据回放，并分别监测 EGO/EXO；EGO 退化不能被混合均值掩盖。

用户已确认，另一个 EXO-only 实验指 **从 AMASS 随机初始化预训练起，全程只用 EXO，之后再做 EXO-only 场景训练**，不是从 EGO 场景权重派生。此实验按剩余时间另行安排，当前不启动；它与统一模型的父权重不同，比较时应同时注明训练历史与计算预算。

## VideoMimic 接触伪标签的后续接入判断

本节为接入建议，**尚未实现或启用 BSTRO 监督**，不改变当前通过验收的配置。当前 `contact_logits` 是受动作损失间接训练的反馈门控，没有独立接触分类监督。优先保留这一基线，再做固定数据、相同父权重和训练预算下的接触监督消融。

核对本地 VideoMimic 提交 `cfded6d85dd55893074c844f74a49297e318980c`：`real2sim/stage0_preprocessing/bstro_contact_detection.py` 保存逐帧、逐人的 `frame_contact_vertices`，维度为 SMPL 的 6890 个顶点，以及 `left_foot_contact` / `right_foot_contact`。流水线 `preprocess_human.sh` 用顶点分数 0.95、脚部超过阈值的顶点比例 0.2 汇总足部标签；Python 默认值则是 0.98 / 0.25。两组均为上游启发式阈值，不是我们数据上验证过的参数，0.95 也不代表已校准的 95% 正确率。[上游代码](https://github.com/hongsukchoi/VideoMimic/blob/cfded6d85dd55893074c844f74a49297e318980c/real2sim/stage0_preprocessing/bstro_contact_detection.py)

BSTRO 从包含被摄人的 RGB 图像预测人体表面的接触概率，不输出该顶点对应的具体场景表面、世界接触坐标或接触力。因此，它可以补充“何时、哪一部位可能接触”的弱标签，但不足以单独恢复 EXO 的深度、全局根轨迹或判断脚是否踩中了正确台阶。原论文在 RICH-test 的全身顶点接触 F1 为 0.708，这不是足部标签准确率，也不能代替目标视频上的检查。[BSTRO 论文](https://arxiv.org/html/2206.09553v1#S6)

建议按以下范围评估，实施前再固定参数和重新验收：

| 阶段 | 建议用途 | 约束 |
| --- | --- | --- |
| 当前 EGO-only 场景基线 | 继续已准备的预测皮肤反馈，暂不加 BSTRO | 等待 GRAIL 检查；不把伪标签加入当前密封配置 |
| 后续带 RGB 的 EXO 视频 | 先评估左右足接触，再尝试低权重辅助分类监督 | 保留软分数；用跟踪质量、时间一致性和独立几何证据筛选；不确定项忽略 |
| 接触几何损失 | 在可靠接触和表面对应已确认时约束距离、稳定支撑期的相对滑动 | 接触不等于足部所有点速度恒为零；踏步换脚、滚动、活动表面须区别处理；不盲目拉到最近点 |
| EGO 训练 | 若有同步第三人称训练视频，可离线提供监督 | 只作训练目标；推理仍只用允许的相机轨迹和可见场景，不能要求佩戴者完整人体 RGB |
| 已有可信人体—场景配准的数据 | 优先使用原生接触标注或经检查的几何派生标签 | 几何派生标签也可能带配准误差；不把当前预测动作自行算出的接触当独立真值 |

未来适配器应按帧名/时间戳与人物 ID 显式连接，缺失检测设 `valid=false`，不能缩短序列后补尾帧，也不能把缺失当作不接触。本地上游单视频脚本按排序后的图像和 bbox 列表 `zip` 配对，并复用首个裁剪框的归一化中心/尺度；若直接接入，缺文件和变化框大小会产生风险，需要先修正或在独立适配器中处理。保存原始分数、有效性、教师权重 SHA、拓扑和标签来源；SMPL 的顶点编号不能直接套到 SMPL-X 或其他原生模板，先做经过核验的拓扑/身体区域映射。

BSTRO 原论文的接触训练使用 RICH，附录 D 明确按 RICH-validation 选模；权重文件名含 `3dpw` 不能证明其接触训练不含 RICH。**用户已确认允许使用在 RICH 上预训练的上游模型，须注明来源；SceneMI 自身训练和选模继续排除 RICH 样本。** 实际接入前仍应核对所用权重及训练来源。其预测只能作为辅助监督，不能充当验证/测试的接触真值。[原论文训练说明](https://arxiv.org/html/2206.09553v1#A4)
