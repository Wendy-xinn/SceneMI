## 结构与可观测几何

每个扩散时刻调用同一冻结去噪器提出动作，用预测的原生体形蒙皮查询 67 个皮肤锚点，再将条件残差注入共享 U-Net 的中间层及两个解码尺度，完成第二次去噪。只训练 767,032 个适配器参数，所有输出投影零初始化。主干、相机条件、体形和旧场景模块均冻结并保持 eval。

关系输入包括局部坐标中的相对位置、邻近表面距离、可信局部平面的方向与偏移、有效点覆盖、可靠性，以及观测到的自由射线／邻近表面／未知状态。平面只由观测点拟合，拒绝点数不足、近似直线、非平面与混合 owner 的邻域；不是物体内部/外部 SDF。法向朝向输入相机，不能据此宣称获得了封闭场景的穿透符号。

已知自由空间仅来自当前帧输入相机至真实首个命中点之前的窄射线，保留端点与近裁剪余量；缺少射线来源的历史点只能提供表面证据。空占据栅格、视锥内缺点、遮挡后方都不能标为空闲。近表面信号不表示身体应贴到该表面；没有有效几何证据时完整分支的注入为零。历史为窗口起点前实际静态观测，当前点逐帧输入，不读取未来表面或完整隐藏网格。

零初始化时与原基座完全一致。对每次 x0 输出使用共同的根平移 0.15 m、6D 旋转分量 0.5 的平滑限制，并保留相对冻结提议的头部/根位置一致性损失。限制不是最终采样轨迹界限，也不是关节角界限；相机一致性是约束项，不能承诺最终误差绝不增加。

## 固定预算的五组验证

| 组别 | 改变什么 | 用途 |
| --- | --- | --- |
| `full` | 完整关系＋内部注入＋可靠性控制 | 验证组合方案 |
| `motion_only` | 相同适配器结构与参数量，输入只有提议动作、相机与时间，不读取具体场景 | 控制新增动作修正容量与额外更新 |
| `points_only` | 保留观测点相对位置、距离和观测状态，移除显式平面关系与其可靠性 | 检查显式关系的增量价值 |
| `late_only` | 三个相同投影仅注入最终隐藏层，经固定通道池化，不改变中间去噪特征 | 检查分层注入的价值；参数数目相同但有效函数空间不完全等同 |
| `ungated` | 输入观测状态仍真实，移除显式可靠性幅度控制 | 检查未知与低可信观测的控制作用；不会把未知标签改成真实空闲 |

每组相同随机种子、batch 8、固定 3000 更新、相同 AdamW/warmup/余弦调度及动作损失。每 1000 步 176 窗口监测，**不根据监测选权重、不提前终止不利组别**。最终固定 3k 评两份预先锁定的验证清单，不做 checkpoint 搜索。每个组别只覆写一份可恢复 `last.pt`；最终比较的是同预算新适配器，不能将旧候选 8k 搜索后选中的 3k 叫作等搜索预算对照。

五组顺序运行：`full → motion_only → points_only → late_only → ungated`。每组完成训练和最终评测后才进入下一组，各组从相同基座独立初始化。总状态中的 `variant` 指当前组；`completed_updates/planned_updates` 指训练步数，`completed_windows/total_windows` 指当前评测进度。每 20 次更新写训练状态，评测每 10 个窗口写状态。

在项目根目录汇总查看五组状态（轻量读取，不运行推理）：

```bash
python -m experiments.offline_camera_retrain_v1.ops status --run runs/scene_ego128_conditioning
```

短程机制验证不等同论文最终实验；一次运行、单一训练/采样 seed 与反复使用的验证集不足以证明统计稳定或测试集泛化。若未改善，保留结果并诊断，不替换为不利的 33k 无场景基线。
