# AMASS EXO 15k 适配：最终结果与下一轮修改

2026-10-26 北京时间 **22:47** 完成训练及最终 EGO 完整验证。结论：当前 EXO 适配仍在改善，但误差过大，且没有保持已提供的准确关节，不满足“保留前置人体、修复遮挡和短暂出画”的新目标。建议保留本轮作为部分关节条件生成对照，修改 EXO 输入与修复路径后再训练新增分支；不从零重训 EGO 先验，也不按原配置直接增加步数。

## 同输入核验：为什么需要修改

新 CPU 审计逐一重建两个完整验证条件，要求输入身份与原评测记录严格相等；只在**同一份可用关节—帧 mask**内比较输入和输出。没有用标签填补隐藏输入，也没有把部分观测当作完整前置人体。

| 验证输入 | 已提供关节的输入误差 / mm ↓ | 同一关节—帧上的输出误差 / mm ↓ |
| --- | ---: | ---: |
| 无位置噪声、关节缺失 | 0.004，近似零 | 372.12 |
| 含噪声、关节及整帧缺失 | 49.18 | 461.75 |

两条件各 2,222 个窗口的可见关节误差都变大。干净条件另有 **169 个窗口、123 个 family** 在整个窗口内 22 关节都可用，此子集输入误差 0.005 mm，生成输出仍为 **385.26 mm**。这说明问题不仅在于隐藏部分存在多解，当前路径也没有保留已知的准确运动。

代码核验确认：采样传入了 EXO 条件，但仍从随机噪声生成完整绝对动作；没有完整估计人体初始化、可靠部分的保留通路或显式观测锚定。本轮关闭了拟合含噪观测的附加 `observed_position` 损失，干净动作监督仍包含全部关节。缺少显式保留机制是可以确认的实现事实；冻结主干适配容量、损失权重等因素的独立贡献尚未做消融，不能把失败全部归因于某一项。

之前固定 9k、64 窗口的平移锚定改善，说明可修复当前生成结果自身的部分全局偏移，**不证明优于视频前置模型**。本次输入/输出核验也不构成真实前置模型评测；它针对已声明的 AMASS 合成观测。

证据：`runs/amass_exo128/review/RESULT.json`、`observed_inputs.jsonl`；审计模块 [`exo_review.py`](../scenemi/exo_review.py)。结果包含输入重建、已完成候选、checkpoint、EGO 比较和源码哈希。原训练及评测的 84 个封存源文件均未修改。

```bash
python -m experiments.offline_camera_retrain_v1.ops.resources run \
  --device cpu --memory-gib 4 --cpu-count 2 -- \
  python -m scenemi.exo_review --output /path/to/new_review_directory
```

## 下一轮：修改 EXO 修复分支，保留 EGO 先验

建议继续使用原 **AMASS EGO-only 55k** 作为冻结动作先验，新增 EXO 初始化修复路径，EGO 模式保持原输出。保留当前 EXO 15k 及其评测作为对照。现有实验没有证明把整个主干解冻或从零重训会更好，因此不把它们列为当前首选。

| 部分 | 当前路径 | 修改要求 |
| --- | --- | --- |
| 初始化 | 随机噪声，只有部分关节条件 | 显式提供前置完整估计人体及根轨迹；缺失段从邻帧建立初值，并保留缺失标记 |
| 遮挡含义 | 被遮挡的关节从输入中删除 | 区分“前置模型仍有估计但不可靠”“相机可见且可靠”“整个人跟踪丢失”；估计存在不等于真实可见 |
| 输出 | 生成整段绝对动作 | 围绕估计初始化产生根平移与姿态修正，可靠部分优先保持；避免逐关节拼接破坏骨架 |
| 可靠度 | 一套合成位置置信度 | 分开表达全局轨迹和局部姿态可靠度：人体姿态可靠也可能有根轨迹漂移 |
| 训练输入 | 部分干净/带噪关节 | 声明的合成完整前置估计，含干净样本、相关姿态误差、缓慢漂移、局部不可靠及整帧缺失；绝不把隐藏 GT 当估计输入 |
| 监督 | 全动作重建为主 | 干净动作监督，并明确检查可靠部分的保持、遮挡/缺帧修复及时间连续性 |
| 选模型 | 两条件平均全局 MPJPE | 先验收可靠部分不明显退化，再比较待修复区域和整体误差；保留 best 与可恢复 last |

修正仍须在合法人体参数/运动表示上完成，旋转经过 SO(3) 处理并重新 FK。若只有世界关节，可以建立关节初始化，但进入当前 201D 扩散状态还需要经过核验的姿态/骨架重建；不能把关节位置直接当作完整 201D 状态。若上游提供原生姿态和体形，则使用其估计值并明确人体格式，不依赖个人 GT 或直接补零转换 betas。

起步阶段先做小规模固定预算验证：原始估计、时间插值、当前条件生成和新初始化修复使用同一输入、同一窗口。必须同时看到可靠部分得到保持、遮挡或缺帧区域相对初始化/插值有收益，才进行大规模训练。可靠度来源、允许退化阈值、修复强度与选模规则必须在该训练开始前写入可执行配置并通过 CPU/CUDA 验收；本记录不是已经验证有效的模型配置。

之后再接三来源无场景适配和场景分支，保持相同初始化与无场景对照。无场景时无法保证消除共同坐标漂移或不可观测的绝对深度偏差；场景阶段再使用实际观测到的几何及相机约束检验这部分收益。

**本轮未启动新训练。** 已完成的是原 15k 最终评测和同输入审计；新的完整初始化修复训练尚未实施或验收。
