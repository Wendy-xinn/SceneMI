# 论文候选模型与最低证据要求

当前将 `scene_ego128_residual` 已选 3k 固定为 **EGO 场景候选**，用于补齐证据。它不是已通过独立测试的最终模型，也不是已经验证的 EGO/EXO 统一模型。新增关系监督 500 步没有超过该父模型，不晋升。

## 必须如实描述的训练流程

1. AMASS EGO-only 预训练，验证选中 50k。
2. EgoBody / TRUMANS / GRAIL 上的相机条件、无场景动作与原生体形适配，验证选中 30k。
3. 冻结动作、相机和体形部分，训练场景条件分支与有界修正；实际探索了 8k 更新，验证选中 3k。

这是分阶段训练的冻结动作先验与场景条件适配方法。分阶段训练本身不妨碍作为正式方法；必须披露第二阶段使用了场景数据集的动作监督，不能把整个先验写成仅用 AMASS 训练，也不能把实际 8k 的选模搜索写成预先固定 3k。两份权重共同定义推理模型，不能只发布适配器却遗漏其基座。

## 已有证据

同一 1416 个验证窗口：独立无场景 113.7933、原联合适配场景版 119.5375、冻结先验场景候选 111.7758 mm。候选相对独立无场景低 2.0174 mm；以选定权重为条件的家族重采样范围为 [-0.9168, 5.1939] mm，不能称稳定、显著改善。候选的 GRAIL 指标未超过独立无场景。

旧场景权重在推理时移除场景会大幅退化，只能证明它对条件路径的依赖，不能作为独立训练的无场景基线。正确与同类错配场景差距很小，当前没有足够证据将修复收益归因于具体几何。新关系监督的 176 窗口结果 112.1088 mm，也没有超过原修复 112.0542 mm。

## 方向讨论记录与后续授权

用户此前要求先确定方向，再开始新训练。原额外无场景 3k 对照已按原定流程完成训练及 1416 窗口评测。后续已明确授权从原无场景 30k 开展三项几何条件实验，范围、固定预算和验证清单见 [SCENE_CONDITIONING_zh.md](SCENE_CONDITIONING_zh.md)；不修改原已封印模型和配置，新结果形成前不晋升候选。

当前无场景模型是相机条件扩散，不是无条件动作模型：预测体形，将虚拟相机转换为头部观测条件，针对 128×201 动作做 x0 预测；训练使用 1000 个噪声时刻，采样使用 20 个 DDIM 时刻。场景关闭时每个时刻只调用一次去噪器。EGO-only 在 AMASS 选定 50k 后，又在三个场景数据集的动作上做了无场景适配 30k；额外对照已完成这个 30k 模型的固定 3k 续训，完整验证 MPJPE 为 124.2720 mm；报告见 `runs/scene_ego128_noscene_low_lr/evaluation/REPORT_zh.md`。

有场景的“两步”指同一个时间步内，先用同一主干提议动作，再按预测人体查询真实已观测几何，第二次调用共享主干细化并施加门控修正；外层仍是一条 DDIM 链。冻结主干只改变参数更新策略，不要求改成两个独立扩散模型或两条采样链。当前 3k 修复版已经采用冻结主干原则。

讨论中的统一方向是共享动作主干，区分 EGO 相机观测适配与 EXO 估计 3D 关节适配。EXO 需要有效性、置信度、连续缺失与坐标/根轨迹误差建模；外部相机不能转换成佩戴者头部轨迹。不能声称 EGO-only 模型完全冻结后，只增加场景分支便获得了 EXO 能力。可先在无场景条件下训练新的 EXO 观测/体形适配，再验证主干是否可保持冻结；编码器容量不够时可能仍需少量任务适配层，该可行性尚未验证。之后才评估共享的场景条件适配；冻结基础能力不能排除共享场景模块的任务干扰。

创新性评估不能只围绕“冻结主干”“加 cross-attention”或“场景扩散”。需结合近邻方法核验可观测场景、人体相对几何查询和 EGO/EXO 观测差异是否形成具体贡献。相关原论文包括 [COIN](https://arxiv.org/abs/2408.16426)、[UniEgoMotion](https://arxiv.org/abs/2508.01126)、[RESELF](https://arxiv.org/abs/2609.01276)；这里只完成相关性初查，没有据此认证新颖性。
