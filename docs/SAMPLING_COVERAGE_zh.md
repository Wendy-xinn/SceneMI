# 已完成训练的随机取窗覆盖审计

2026-10-26。结论来自完整训练日志与实际合格训练序列，不由滑窗数量或更新次数估算。用户核查覆盖率后决定保留当前随机取样，暂不采用 64 帧滑动方案。

## 实际训练规则

AMASS 从合格动作、原始/镜像版本及所有合法起点中随机抽取 128 帧窗口；三来源训练先等权选择数据集，再选家族、录制和合法起点。候选起点间隔是一帧，但训练没有按 0、1、2…顺序遍历它们。历史实现确实没有使用用户要求的固定 64 帧网格。

训练窗口允许重叠，也允许重复抽到同一动作或录制，没有优先未抽样数据的队列或同批次序列去重。将候选改为 64 帧网格并不能避免跨更新重复抽样；同为 55k 次更新，候选变少反而更容易重复相同起点。不能预设固定网格会提高精度。

## 实测覆盖

“帧覆盖”是所有实际训练窗口所监督的合格源时间帧的并集；AMASS 原始/镜像合并计时。它不表示 EXO 所有输入关节都可见，不表示每一个可能窗口都被抽到，也不包含已裁掉或质量筛掉的原始帧。

| 已完成实验 | 观测模式 | 抽到的序列 / 合格序列 | 监督覆盖帧 / 合格帧 | 帧覆盖率 |
| --- | --- | ---: | ---: | ---: |
| AMASS EGO-only 55k | EGO | 7,485 / 7,485 | 2,992,210 / 3,108,138 | 96.27% |
| AMASS 混训 55k | EGO | 7,485 / 7,485 | 2,806,510 / 3,108,138 | 90.30% |
| AMASS 混训 55k | EXO | 7,485 / 7,485 | 2,806,832 / 3,108,138 | 90.31% |
| AMASS 混训 55k | 两模式并集 | 7,485 / 7,485 | 2,991,528 / 3,108,138 | 96.25% |
| 三来源 EGO 无场景 30k | EGO | 7,948 / 8,055 | 2,600,200 / 2,798,180 | 92.92% |

AMASS EGO-only 每条动作至少抽到 32 次，序列帧覆盖率中位数 99.39%，最低 65.22%；没有动作低于 50%。混训 EGO 模式有 16 条、EXO 模式有 11 条长动作低于 50% 覆盖，两个模式合并后没有此类动作。不能将两个模式的覆盖直接当成各自都获得了相同训练量。

三来源无场景 30k 的细分：

| 来源 | 抽到的序列 / 合格序列 | 家族覆盖 | 合格帧覆盖率 |
| --- | ---: | ---: | ---: |
| EgoBody | 175 / 175 | 63 / 63 | 99.64% |
| TRUMANS | 469 / 469 | 469 / 469 | 98.91% |
| GRAIL | 7,304 / 7,411 | 3,987 / 3,987 | 88.11% |

GRAIL 有 107 条录制未被该轮抽到，但所有合格家族都被抽到。家族等权、家族内录制有放回抽样会使部分录制采样不足；后续可以改善覆盖调度，不能声称原训练已经遍历全部 GRAIL 录制。

这些结果支持继续使用现有 AMASS 基座，不支持仅因随机取窗而推倒重训。覆盖率不能证明模型已收敛，也不能解释全部精度差距。

## 此前讨论的固定滑窗方案（本次不采用）

若另立 128/64 实验，尾部应使用以最后有效帧结束的完整 128 帧窗口，不能补零、复制帧或跨越不合格区间。它与最后一个常规窗可能高度重叠，必须去掉相同起点并明示尾窗规则。128/64 是另一套训练协议，不应重写历史合同；热启动旧权重后改网格也不能标为全程 128/64 从零训练。
