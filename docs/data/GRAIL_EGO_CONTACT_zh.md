# GRAIL EGO：场景可见性与动作接触联合筛选

**2026-10-22 人工复核发现 v1 漏筛，当前候选清单暂停作为最终场景训练数据。** 页面第 10 个随机案例 `straight_aged_wood_stairs_with_8_steps_no_handrails_no_turns__0002` 第 82 帧，源估计接触概率为 0.994、足部中心速度约 0.024 m/s。整个脚部的最小竖直间距约 2.46 cm、最近三角面距离约 2.42 cm，因此没有触发原规则；最低 15% 皮肤顶点的向下间距为 16.56–约 16.74 cm（最小值与中位数），且这些顶点在 3 cm 内没有水平面支撑。仅按最低点/最近表面距离不能验证脚底支撑面积，尤其会漏掉踏边或近立面的情况。局部复核 65–100 帧中，75–100 帧均有源支撑概率 >0.8 而上述底部顶点无 3 cm 内支撑。该证据不是全足接触面积或动力学结论，但已足以否定 v1 通过意味着接触正确。

两个随机坐下案例的完整源物体均没有任何一帧全部位于主相机视锥内。相机为 66.56°×40.49°、额外俯角 0°、随头部转动；原可见性门槛只保证出现一部分表面，不保证完整椅子。顶点入视锥比例不是可见表面积或遮挡率。用户随后确认保留“双眼中点前方 2 cm”的现有定义。新版脚底支撑、坐下前真实观测及合成椅子训练候选见 [v2 说明](GRAIL_SUPPORT_V2_zh.md)。

详细测量在本地 `runs/grail_preview/filtered_ego_review/CASE10_CONTACT_CAMERA_AUDIT.json`；隔离说明在 `runs/grail_ego_contact/full/QUALITY_HOLD.json`，原始完整扫描账本和哈希保持不变。下文数字保留为 **v1 筛查结果**，不代表已完成足底支撑复核。此问题不影响关闭场景输入的独立 AMASS 阶段 A。

## 计算与核验

固定使用预处理时已核验的 G1 SMPL-X 模板、原生比例和零 betas，不再次乘原始 `human_data.scale`。保存的所有 55 个关节旋转均参与 LBS，包含手、脸对姿态修正的贡献。只输出足部与臀部共 **661 个顶点**：左右足 240/241 个、后侧臀部 180 个，使用完整姿态修正与关节变换，不用关节点代替脚底。

每次任务开始都与完整 SMPL-X 的 5 个时刻比较；51 条训练集核验样本及此前 10 条预览也做了该比较。训练样本最大误差小于 0.001 mm。正式扫描每条序列均核对与导出 22 关节的一致性，并校验人体参数、物体、地面和原始接触概率对应的文件哈希。

核验样本为每类可见性通过的训练数据随机 10 条，seed=20261022，另含已知的训练集楼梯问题样本。此前预览中的验证/测试样本只作对照，不用于调整规则。初版垂直射线曾把上方扶手或台阶边缘误当成身体穿透，因此改为结合最近三角面、封闭体内部占用和最近水平支撑面；相应回归检查见下文。

## 初版判据

参数独立保存于 [`configs/grail_ego_contact.json`](../../configs/grail_ego_contact.json)，任务开始时封存输入、规则和代码哈希。

| 情况 | 持续候选的条件 |
|---|---|
| 地形动作双脚无支撑 | 左右脚最低皮肤点都高于竖直下方表面 5 cm，且各脚离最近三角面超过 4 cm |
| 估计支撑脚悬空 | 原始两通道接触概率均超过 0.8，但该脚满足上述高度与最近距离条件 |
| 深入地面或物体 | 至少 10% 足部顶点深入地面 4 cm；对封闭物体，还要求位于物体内部且离最近表面超过 4 cm。非封闭物体只能标记待复核的深度重叠 |
| 估计支撑脚滑动 | 接触概率超过 0.8、距支撑高度不超过 3 cm，脚跟与脚尖小块都水平移动超过 0.30 m/s，且至少一块垂直速度低于 0.12 m/s |
| 已坐下但无座面支撑 | 双大腿接近水平、pelvis 垂直运动低于 0.25 m/s；臀部下方没有足够水平支撑，或臀部支撑间隙超过 6 cm、重叠超过 4 cm |

候选需要连续 **8 帧（约 0.27 s）**；短暂边缘切换不因此剔除。事件前后各保留 6 帧复核余量，排除与其重叠的 128 帧训练窗口。正常单脚摆动不会因抬高而被标记；坐下类不应用“双脚必须贴地”的条件。找不到稳定坐姿或可靠支撑的情况作为待复核保留原始数据，不能据此宣称动作错误。

坐姿支撑先找水平程度 `abs(normal_y)>=0.7`、高于地面 15 cm 的三角面，再查臀部皮肤到最近水平面的关系，仅接受水平投影偏差不超过 4 cm 的查询。它避免把悬在上面的扶手自动当成座面，但对特殊曲面、软座垫或真实多点支撑仍有限制。

这些规则是保守的数据一致性筛查：原始接触概率只是估计，不能升级为接触真值；持续双脚离地可能属于跳跃等动作，未核实用途的片段先从本次场景接触训练清单中隔离。扫描也不覆盖全身自碰撞、手臂碰撞、动力学稳定性或足底完整接触面积。

- 接触清单保留起点 **0–70**，共 71 个窗口。
- 起点 **71–173** 的 103 个窗口与隔离区间重叠，不进入本次 EGO 场景训练。

## 随机窗口复核

`runs/grail_preview/filtered_ego_review/SELECTION.json` 固定本次 seed=4270313313：从各类别保留的训练序列中无放回随机选两条，再在各自合格窗口中等概率选一个起点，共 10 个新窗口。首次抽样后不因观感重抽。抽样过程、源清单哈希与窗口交集已独立重现。

本地页面 `http://localhost:8840/` 的 01–10 为新随机窗口，默认只循环播放选中的 128 帧；11–14 为明确标注的固定对照：旧坐下样本两条、旧楼梯保留前段和筛除后段。两条旧坐下因 EGO 观测不足整体排除。对照使用先前保存的相同源网格，不重建为更好看的动作。

## 输出与恢复

`runs/grail_ego_contact/full/` 内：

| 文件 | 用途 |
|---|---|
| `JOB.json` | 固定配置、接触/可见性实现与上游窗口清单哈希 |
| `STATUS.json` | 全量进度、失败信息、最终类别统计与产物哈希 |
| `FK_EQUIVALENCE.json` | 本次启动的局部/完整 SMPL-X 比较 |
| `CONTACT_RECORDS.jsonl` | 每条序列的事件、源身份、窗口交集与审核统计，可恢复 |
| `train/manifest.jsonl` | 至少保留一个窗口的训练序列 |
| `train/windows.jsonl` | 同时通过可见性与接触筛查的起始帧范围；必须用于实际窗口采样 |
| `train/excluded.jsonl` | 可见性通过但已无合格接触窗口的训练序列与原因 |

最终 GRAIL EGO 场景训练应使用此处的序列和窗口交集，不能只换序列清单后任意抽取窗口。仍需同一录制真实观察历史，不能使用未来帧场景并集。尚未通过可见性的排除记录仍位于 `runs/grail_ego_filter/train/excluded.jsonl`。

扫描使用受限 **2.5 GiB / 4 CPU**，不使用 GPU，逐条写入记录。断点恢复验证相同代码、规则和上游身份，截断中断留下的尾部不完整 JSON 行；已完成记录不重复计算。所有任务记录保持 `physics_validity_proven=false`。

```bash
python -m experiments.offline_camera_retrain_v1.ops.resources run \
  --device cpu --memory-gib 2.5 --cpu-count 4 -- \
  env CUDA_VISIBLE_DEVICES= python -m scenemi grail contact-scan \
  --visibility runs/grail_ego_filter \
  --output runs/grail_ego_contact/full --workers 4
```
