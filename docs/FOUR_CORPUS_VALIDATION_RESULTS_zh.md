# 四数据集无场景完整验证结果（EGO / EXO）

本报告来自 `runs/scene_joint128_replay` 的完整 validation。每个 checkpoint 均覆盖 EGO 5,693 个窗口和 EXO 四种条件共 23,048 个条件窗口；不使用 test。单位均为 mm，除 MPJVE 外。

**本报告所有checkpoint均为无场景模型。**训练和验证来源为AMASS、EgoBody、TRUMANS、GRAIL；
step0是AMASS预训练父版本转入本阶段的初始模型，step64/512/2000是四数据集无场景混训后的候选。
这里没有与有场景模型作对比。旧场景1000步的三数据集版本诊断另见
[旧场景版本诊断](../runs/scene_joint128_comparison/step_001000_full_gpu/REPORT_zh.md)，
它不包含AMASS，也不属于严格的场景输入消融。

## 与后续场景训练的比较口径

后续场景实验应在同一评估协议下重新成对评估，固定validation清单、窗口、初始输入、
随机噪声和指标；不能把另一采样执行或聚合口径的结果直接与本报告行拼接相减。
四数据集能力保持应另保留AMASS验证；三原生数据集的场景实验则明确声明其范围。
若要归因于场景输入，还须使用相同父模型、训练预算和可比结构的无几何对照，
控制除场景信息外的其他差异。建议保留逐数据集、逐EXO条件结果及三来源等权汇总。

step 2000 相对初始无场景模型的三数据集变化：EGO MPJPE 在 EgoBody / TRUMANS / GRAIL 分别下降 56.2% / 69.0% / 84.8%；EXO 修复区域 MPJPE 在 tracking、occlusion、gap 三种条件下分别为：

| 条件 | EgoBody | TRUMANS | GRAIL |
|---|---:|---:|---:|
| tracking | -39.8% | -4.3% | -8.2% |
| occlusion | -37.4% | -6.6% | -9.4% |
| gap | -54.2% | -7.0% | -8.7% |

完整原始聚合结果仍保存在每个 `selection/step_*/RESULT.json`；逐窗口分片保存在对应目录下的 `*_*.json`。
