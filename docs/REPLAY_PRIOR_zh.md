## 为什么更换接续点

旧 AMASS 冻结 EXO 续训完成了 20k 追加更新，完整验证选择追加 15k。对应 tracking / occlusion / gap 修复区域误差为 55.410 / 100.341 / 158.477 mm。遮挡结果仍未超过另一个已训练时间修复对照的 99.112 mm，不能称为所有对照中最好。

旧三数据集无场景任务从 EGO 55k 与该 EXO 适配器起步，部分解冻共享主干，没有 AMASS 回放。500 步完整验证中，本域 EGO 三数据集等权、再按 family 等权的 MPJPE 从 807.604 降至 249.152 mm，EXO 也改善；但 AMASS EGO 窗口均值从 149.704 升至 390.233 mm。正式保留能力门槛使用的是 family 均值（153.348 → 363.226 mm），同样失败。这个结果支持加入回放，不足以证明某个回放比例必然有效。1500 步验证未全部完成，不能用其局部结果代替完整结果。

下一轮应等待 AMASS scratch 的 110k 更新与最终完整验证结束，使用其最终 `selection/BEST.json` 指定的 checkpoint。110k 的 last 不自动等于 best。必须核对完成状态、完整验证资格、父协议和 checkpoint SHA；复制/固定父权重后再封存新协议。

## 建议训练设定

- 单个共享扩散主干，保留 EXO 边界编码器与注入层；EGO/EXO 各占一半，每个优化更新都包含两种条件。
- 已完成的吞吐探针使用 AMASS / EgoBody / TRUMANS / GRAIL 每批各占四分之一，loss 也按四源等权。这不是最终采样决策；数据规模、回放与 loss 权重的联合复核见下节。
- 先做无场景 motion prior 适配，再考虑场景分支。共享主干沿用原生适配中已定义的部分解冻范围；大 batch 的学习率、warmup、AdamW 状态与样本预算需联合验证，不机械照搬旧学习率或线性倍增。
- AMASS 保留原生 SMPL-H 16 维形状监督；原生数据使用各自 SMPL / SMPL-X 10 维解码头或 G1 固定模板。EGO 仍仅由相机观测预测体形，EXO 使用模拟前置估计的骨架、初始化和可靠度。统一 collate 中的占位标签不进入推理，也不表示将不同人体模型的形状系数互相补零转换。
- EGO 相机保持连续，虚拟安装点保持双眼中点前方 2 cm。EXO 扰动、遮挡和短时出画沿用已声明分布；TRUMANS 使用验收后的移动相机，EgoBody/GRAIL 保留各自既定相机。
- 三数据集必须使用 `configs/scene_data_current.json` 及匹配的 inventory 检查；遵守筛选后的 GRAIL 动作范围。训练只读 train；不加入 RICH，不读取独立 test。
- 建议预算先按 **256,000 个抽样窗口**估算，其中原生三数据集合计 192,000、AMASS 64,000，避免增大 batch 后无意减少本域样本曝光。更新次数、warmup 和验证间隔均由最终实测 batch 换算并封存。训练质量不能由相同样本数保证。

## 采样比例与大 batch 优化的联合复核

用户随后要求将数据体量、梯度回传和大 batch 联合考虑。此前将“同样样本下更新少”作为主要风险解释不够完整：更少的更新不自动意味着性能更差，恰当的优化器设置可以支持更大的 batch；目前的实验只验证吞吐、数据一致性和有限梯度，尚未证明质量等价。

四源等权代表人为选择任务权重，不代表它们规模相等，也不保证最合适。当前不含镜像的可用训练帧为 AMASS 3,108,138；EgoBody EGO / EXO 202,950 / 233,260；TRUMANS 1,031,365；GRAIL 1,563,865。相同来源概率下，EgoBody 每帧的抽样强度明显高于 GRAIL；实际加载器还按 family/recording 分层，所以这些帧数仅是规模代理，不能当作独立样本数或准确覆盖率。

一个可评审候选是固定 AMASS 回放 25%，原生三源按可用帧的平方根分配剩余 75%。为保持同一来源的 EGO/EXO 配对，规模代理采用两模式可用帧的平均值，不将两种视角相加宣称独立数据增加。计算约为 25.00% / 12.82% / 27.87% / 34.32%；batch 128 可实现为：

| 来源 | 每批窗口 | EGO | EXO | 实际概率 |
|---|---:|---:|---:|---:|
| AMASS | 32 | 16 | 16 | 25.000% |
| EgoBody | 16 | 8 | 8 | 12.500% |
| TRUMANS | 36 | 18 | 18 | 28.125% |
| GRAIL | 44 | 22 | 22 | 34.375% |

该方案兼顾体量和小来源覆盖，是候选，尚未用于正式训练。原生三源总预算不变并不代表各源曝光不变：256k 窗口对应 AMASS / EgoBody / TRUMANS / GRAIL 各 64k / 32k / 72k / 88k 个抽样窗口。

采样概率 p 和目标 loss 权重 w 必须分别记录。当前探针先在每个来源内计算 mean，再对四个来源取 mean；只改数量配额，梯度目标仍是四源等权。若采用上表作为目标权重，需要明确计算 `L = 0.5 * sum(w[d] * L_ego[d]) + 0.5 * sum(w[d] * L_exo[d])`。不能在已经按样本平均后再次乘同一采样概率，造成重复加权。若希望 p 与 w 不同，也应明确声明其目的。

当前梯度实现为：每次先清零，EGO、EXO 各做一次 backward，合并梯度后统一裁剪，再做一次 AdamW step；没有跨多个 batch 的梯度累积。均值 loss 使梯度不会随着样本数自动乘四。把一次大批次切成四次 backward 后再 step，仍只产生一次参数更新；重复使用旧梯度 step 四次也不等价于四次按新参数重算的更新。

下一步优化核验应比较相同父权重上的 batch 32 参考、batch 128 原学习率、batch 128 两倍学习率候选。两倍来自 sqrt(128/32)，只作候选；Adam 的完整 SDE 缩放还涉及动量和 epsilon，AdamW 又有 weight decay，不能声称仅放大学习率即与原配置等价。参考：[Malladi 等，NeurIPS 2022](https://papers.neurips.cc/paper_files/paper/2022/hash/32ac710102f0620d0f28d5d05a44fe08-Abstract-Conference.html)、[PyTorch 2.8 梯度累积说明](https://docs.pytorch.org/docs/2.8/notes/amp_examples.html#gradient-accumulation)。

短对照必须使用相同的训练案例序列、按案例固定的扰动与扩散噪声，只改变分批/优化设置。现有探针按优化步派生样本，不满足跨 batch 的相同案例流要求，不能直接当作这种质量对照。warmup / 衰减按样本曝光换算，更新数另行记录；初始与最终完整验证选择协议保持明确。短验证只排除明显不稳定，不代替最终完整验证选 checkpoint。

同时记录共享参数上 EGO/EXO 的梯度范数与夹角，判断量级失衡或冲突，之后再决定是否需要调整任务权重或引入梯度冲突处理。EGO/EXO 各 50% 样本不表示梯度影响必然各半。修复分支适配前后两次共享主干的梯度仍应完整保留，不以 detach 参考输出来改变现有模型定义。
