# 下一轮具体方案（未启动）

目标是保留完整轨迹效果，同时让模型能接收只有位置或不可靠朝向的视频关节观测。先完成受控短训，再判断是否扩展训练。

1. **将输入语义适配和噪声鲁棒性拆开。** 保留camera与body_joint明确类型；GT head_joint只用于训练模拟与理想上界，部署从实际视频关节定义或已知相机安装标定转换。真人PV未知安装关系保留camera类型，不用平均偏移或验证GT标定。比对同类型输入的joint_clean控制组，另保留相机参考。
2. **先做旋转缺失单变量。** 在完整干净头部观测中仅加入约10–20%的position-only输入；不同时加位置漂移、缺失段或新软损失。只有位置时32.58→24.73cm是本轮最明确的收益，但还需要区分是哪一种增广产生的。
3. **再独立加入温和噪声。** 从80%以上完整干净样本开始；小幅平滑位置偏差/漂移、旋转噪声、短缺失采用互斥类型，避免独立叠加使干净比例降到14.5%。先从约1cm和2–3°的小扰动开始，再针对实际视频估计误差校准强度；保持GT动作监督。逐帧白噪声不足以代表视频误差。
4. **可信度和软损失分成两个消融。** 在相同观测扰动、mask及噪声种子下，分别比较无可信度、仅可信度、可信度加小权重软损失；避免本轮两者同时改变。估计器分数需要数据校准，不能直接当作精确误差或硬约束权重。
5. **给新条件编码器单独的适配预算。** 先试仅适配条件编码器、再联合小学习率微调，与全模型从第一步共同微调配对；至少完整走过warmup后的训练段。本轮500步筛选不能排除语义适配尚未完成。可以显式提供由可用观测计算的轨迹速度/角速度作为下一项单变量，用于转向方向；绝不能把GT骨盆朝向当作实际推理输入。
6. **支撑指标同时看上下两侧。** 同时约束/评估悬浮与穿透、脚滑、颈/胸和转角不足；原GT足部高度代理还应在可见真实场景几何上复核。降低悬浮而加大穿透不能入选。初筛通过后，在未参与开发的录制/序列上核验，再考虑55k。

继续保持软条件，不进行精确头部投影或统一根平移对齐。当前head位置-only误差约24.6cm，完整输入下新增方案仍退化；没有理由直接扩大头部硬约束或升级为正式长训。上述是后续方案，本轮已完成的训练和评估数量以RESULTS_zh.md为准。
