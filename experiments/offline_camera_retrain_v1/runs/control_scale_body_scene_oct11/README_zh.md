# 约束尺度与身体局部场景：顺序配对实验

本轮只检验两个增量，均从原始55k独立初始化600步；第二组不加载第一组权重。参考是上轮支撑覆盖600步，原55k和参考都只用于评分。

1. scale_calibrated：保留支撑覆盖、回放、累计转向和原接触BCE，新增容差归一化的绝对head位置/旋转以及head相对root/spine/neck旋转监督。
2. body_local：同样损失，再添加身体22关节周围的已观测表面方向/距离条件。每个扩散步先预测x0，再按其FK关节查询，第二次前向生成最终x0。查询不读取GT身体或GT接触。

## 尺度排查

审计TRAIN8窗口×4状态（t=50/500/950的q-noise，以及冻结55k生成回放t=50），覆盖四个数据组。记录输出梯度及共享条件编码器梯度；后者不是全模型梯度，也不能直接证明优化效果。

原head位置MSE使用米平方，支撑项使用厘米归一化；同样厘米误差不能仅按loss数值比较。位置新容差5cm，旋转新容差5度，head-body相对旋转15度，均采用Huber型目标。初始提出的权重在条件编码器上明显过强，TRAIN审计后整体缩小到0.1，有效系数位置0.020/绝对旋转0.002/相对旋转0.010。没有按验证集表现调参。初始51步预检在保存权重前终止，记录于preflight_abort.json。

累计转向路径损失在固定角速度偏差下随时长约平方增长（64/128/192帧审计见duration_scaling_audit.json）。本轮统一128帧，没有声称已修复混合窗口时长尺度。原接触BCE的共同signal乘子在分子/分母抵消，本轮为隔离变量保留原BCE；接触标签覆盖扩展也尚未并入这两组。

置信度接口已验证0跳过、0.5减半；当前合成相机条件默认1，并非真实视频估计的不确定性标定。新绝对head监督使用训练标签，仍由模型隐式学习相机安装偏置，没有将GT安装变换传入推理。

## 身体局部场景

半径0.75m，按关节局部坐标输出最近表面方向、距离、有效mask及动态标记，132维经MLP加入原32维帧条件。新MLP末层零初始化，初始输出与原模型一致；独立模块初始化保留随机数流。原相机BPS仍保留，因此这个实验是增加身体条件，不是删除相机条件。

静态点按各帧first-observed时间取前缀，动态点只取对应当前帧已观测物体，不累积到静态记忆。未知区间为mask，不作为空闲空间。查询覆盖膝、踝、臀、躯干等，不局限相机周围。当前是可学习距离/方向条件，没有有符号SDF、表面法向穿透项或完整mesh碰撞保证。计算每个扩散步多一次前向；训练预查询停梯度。

## 验证与保留

全128帧纯噪声DDIM20；只给已知相机/场景与配置身体模板，无GT初态或身体历史、无GT推理投影。固定850/906，加16窗口×2种子主面板及32窗口×2种子确认，共98条，每条对照四个模型。确认面板已经在开发中曝光，不能当独立测试集。

验收同时查看绝对朝向、转向幅度、原生全足部接触点滑动、接触帧覆盖、末段高度、脚步幅度及腿角加速度。门槛在评分前记录，不能因平均重建误差改善而改口通过。相机重建的GT首帧固定安装标定只用于绘图/评分，不能代表部署时可获得安装估计。

每组仅保留一个最终eval-only last.pt；没有optimizer/best/编号checkpoint。所有原始数据、活动缓存和正式55k均保留。代码与小记录备份GitHub，权重和可视化数组留本地。

## 局部查询覆盖诊断

额外在与尺度审计相同8个TRAIN窗口比较GT身体（仅诊断）与原55k生成的表面覆盖。部分EgoBody窗口两者都接近零，因此不能把所有低覆盖归因于生成偏移。世界坐标下独立KD查询与anchor坐标查询在24帧最大距离差1.97e-07m，验证了共同变换；GT头关节与已知相机距离约0.1–0.16m，没有直接把相机位置当头关节。这是样本诊断，不能证明全部缓存或全部数据都无问题。见TRAIN_body_scene_coordinate_audit.json与TRAIN_body_scene_coverage_audit.json。

## 第三组：角度分项平衡

前两组98条评分均未达到联合目标，局部适配器静音只改变850/906平均FK约0.046/0.049cm。完整主干梯度进一步拆分发现，t50时新增位置梯度约3.016，而新增head旋转约0.299、身体相对旋转约0.255；t950时身体耦合约0.00112。此前整体缩放掩盖了位置与角度的失衡。

angular_balanced仍从原55k独立600步，位置系数维持.02，绝对head角度由.002变.02，身体相对角度由.01变.10，身体噪声权重由alpha变.25+.75alpha。选择依据TRAIN32分项完整主干梯度；不加载局部适配器，不改变足部/场景/BCE目标，不引入GT推理初态。它是第三项后续假设，不是对已失败结果修改验收门槛。单独协议及评估保存在angular_balance_eval。

## 第四组：骨盆绝对朝向

第三组98条配对评估仍未修好850/906的身体转向，不能声称角度加权已有效。进一步验证head-body相对旋转对共同root旋转的梯度约为零（属于旋转不变性，不是计算错误），不能直接代替全局root监督。root_facing在角度平衡目标上仅新增TRAIN native骨盆绝对SO(3)损失，15度容差、.25+.75alpha权重；原55k独立600步，没有GT初态/身体前缀或推理投影。

TRAIN32完整主干梯度探测系数.05，q50范数.539对比基础2.033；选择.20使root梯度与基础项量级接近，系数四倍，未按新模型验证结果调参。两个固定例子的GT水平forward投影都>.3，生成root/腿6D向量范数也未近零，未发现这些指标被姿态退化伪造。仍沿用相同朝向/脚步门槛，结果单独保存root_facing_eval。
