# Exo 遮挡恢复定位、源手臂异常与 TRUMANS 相机复核

2026-10-12。训练继续暂停，优化器步数为 0。当前保留有效关节按 confidence 降权，0.7 仅为可视化诊断阈值。本文区分当前实现、直接验证的事实和下一步方案。

## 1. 研究目标与共享模型

建议主问题定义为：**在同一世界坐标下，利用不确定的人体观测与已观察场景，恢复遮挡部位的自然全身动作；exo 优先证明遮挡恢复增益，同时共享 ego 的稀疏观测动作先验。**

统一的实质是相同身体状态、动作先验和场景关系模型，接受两类不确定观测：ego 是相机转换后的头部及可选手部轨迹；exo 是外部前端身体轨迹及遮挡相关不确定性。相机是观察者，动作是目标人物，二者不绑定。共享输出头是合理实现，但本身不足以成为研究贡献；必须验证共享训练相对独立训练是否有迁移收益，是否损害可见部位、全局定位或原有 ego 表现。当前新模型尚未训练，没有已证明统一效果的结论。

可以利用前端完整身体，但应区分观测与推断：

|来源|作用|约束|
|---|---|---|
|可见关节及其轨迹|保持可靠动作和全局定位|按校准后的观测置信度约束|
|前端完整 SMPL(-X) proposal|给隐藏部位、root 朝向和局部查询提供初值／软先验|独立 prior token 或分支，附部位不确定性和来源|
|同视角已观察场景表面|提供支撑、交互位置、障碍及接触关系|受场景和对应关系可靠性控制|

完全不可见关节的测量 confidence 可以为 0，但其前端推断仍可作为低可信 proposal；这需要独立 prior 语义。不能把隐藏 GT 填回输入，也不能把前端隐藏关节预测当高可信观测。当前 sanitizer 会清空 confidence=0 的观测通路，尚没有独立外部 full-body proposal 分支；每步第一遍全身 proposal 来自生成器自身。

扩散修复 noisy／occluded 动作已有相关工作，例如 [RoHM](https://arxiv.org/abs/2401.08570) 恢复全局一致动作。建议把区别落实在可见场景条件的增益、观察者／目标统一表达及 ego/exo 共享迁移，避免仅以使用扩散作为区别。

## 2. 降权与标注质量需要分开

训练配置没有改成 0.7 硬筛选；viser 现在也默认有效关节 + confidence 降权。完全无可用观测时保留 mask／零值；部分可见、低可信估计继续保留并降权。

当前 confidence 是 first-hit 可见皮肤比例和像素支撑，是理想跟踪器的几何模拟，没有评估真实前端误差或源拟合错误。后续应分开记录可见性、前端估计可靠性、完整动作标注质量。被遮挡的部位可以有可靠多视角 GT；可见部位也可以有错误拟合。**观测 confidence 与监督质量不是同一个变量。**

不能只按统一速度／加速度阈值删除快动作，应联合局部旋转跳变、骨架关系、重投影和源标注信息。规则在 TRAIN 拟合／校准；validation 用固定质量分层单独报告，不能根据生成误差删除困难样本。

## 4. TRUMANS 两套 SMPL-X 的相机恢复

两例 world／camera 文件的 local body pose、双手、jaw、expression、betas 完全一致，仅 global orientation／translation 改变；[官方数据说明](https://github.com/jnnan/trumans_utils#trumans-dataset) 也明确两个目录的坐标含义。已恢复两条逐帧移动相机外参。

约定 `X_camera = R_cw X_world + t_cw`，同一 native 身体的 shaped rest pelvis 为 J0：

```text
R_cw = R_global_camera @ R_global_world.T
t_cw = (transl_camera + J0) - R_cw @ (transl_world + J0)
camera_position_world = -R_cw.T @ t_cw
```

SMPL-X 根关节是 transl+J0，直接用 transl 相减会漏掉旋转中心补偿。本次使用与 native30 一致的 male SMPL-X、零 betas；J0≈[0.001168, −0.366841, 0.012669] m。更换 native 体型／模板时应重新计算 J0，不能把这个数值当所有人的固定偏移。

恢复结果本地保存为 `TRUMANS_*_RECOVERED_EXTRINSICS.npz`，含全部源帧 R/t、world camera position、camera-to-world rotation、源帧 ID、J0；SHA 见审计 JSON。网格检验覆盖片段和源序列均匀位置，没有逐帧 forward 全部 3751 帧；全部帧 local 参数相等及旋转正交性已检查。

**3D↔3D 能恢复外参，不能单独确定 K、畸变或图像边界。** camera-coordinate 的像素轴约定还需渲染代码或图像重投影确认。本地未发现这两条原始渲染视频／blend 相机文件。因此六例缓存继续使用明确标注的合成固定视角，没有把恢复的 R/t 与猜测 K 拼接后称为真实相机测试。补齐 K、边界和约定后才重导出对应渲染视角的遮挡。

另外，两个 camera-coordinate 文件中 pelvis 的 Z 均为负（大约 −2.18…−1.26 m），而当前 first-hit 使用 CV 正 Z 向前。**已恢复矩阵表达的是发布文件的 camera axes，不能直接当 CV optical extrinsics 使用。** 需要确认并整体转换相机坐标约定；只对单根轴取反可能变成反射而不是合法 SO(3)。恢复结果记录了这项边界，不通过随意 flip 或镜像人体修正。

## 5. 真实遮挡与模拟增广

建议训练／评估都覆盖真实场景与人物造成的遮挡，模拟增广补充稀有情况。真实视角的几何 mask 和真实视频前端误差是两个层次：

|数据层次|用途|边界|
|---|---|---|
|真实标定视点 + 原场景／人物几何|得到结构正确的物体／人／自身遮挡和出画 mask|位置还是理想 GT tracker|
|同一视频前端预测 + 同期完整 GT|学修复估计错误及保留可靠动作|需置信度、帧和目标身份对齐|
|采样视点、遮挡人／物、裁切、连续丢失|补足遮挡分布与可控强度实验|明确标为模拟，不能替代真实评估|

六例不是遮挡强度平衡训练集：EgoBody 两例以人物遮挡为主；TRUMANS moving chair 是局部下肢／pelvis 遮挡，sit down 是轻遮挡对照；RICH 主要有局部腿部／交互物遮挡。完整 GT 显示不表示完整人体都是输入，但用户指出强遮挡覆盖不足是对的。当前 exo 正式 sampler 也仅覆盖 EgoBody，另两套还未接入训练。

正式清单需要按遮挡类型、body22 部位、可见比例、连续时长和窗口内最严重帧分层，不能只统计窗口里有过一次遮挡。采样同时保留轻／无遮挡，避免可靠输入被普遍修坏；跨数据集像素预算／confidence 应归一化再比较。

原扫描和 GT 身体可以用于模拟 visibility／监督，但生成器只能获得相应视角已观察表面。目标完整皮肤和遮挡后完整扫描不能入条件。当前离线同窗口静态记忆允许其他帧已看过的表面；前端对照应使用相同离线预算。

## 6. 局部查询的当前边界与建议

**当前第一步就查询预测全身的 67 个固定 vertex**。每步先由生成器得到 x0，再做 FK／skinning；不会使用 GT 全身作为查询位置。高噪声时 anchor 中心以 `w=(1−alpha_bar)×confidence×position_mask` 向可信关节混合；低可信／不可见部位仍留在预测身体。

8／25／60 cm 三尺度在所有步骤同时存在，每尺度8邻点；局部条件／反馈乘 alpha_bar²。**查询操作本身没有先只启用可信部位，也没有逐渐扩大关节集合或半径。** 低噪声门控不等于 query 的可靠性课程。

建议从可信支点及可靠前端 proposal 开始，逐渐让更多预测身体部位发挥局部作用：

1. 高噪声：全局 patch 保留；可信关节附近做粗范围查询，无可靠位置的身体部位降低局部权重，避免随机脚位置带来错误接触反馈。
2. 中噪声：根据 proposal 不确定性、跨去噪步几何稳定性、有效邻点逐步开放 pelvis、腿脚和交互手部；不能用隐藏 GT 决定 query 是否可靠。
3. 低噪声：稳定皮肤 vertex 加强 8 cm 精细查询／接触；root 位置和局部旋转都可修正，同时保护高可信轨迹。

“扩大”主要是纳入更多身体部位；空间半径通常先粗后细，未必越去噪越大。可先调整现有三尺度的阶段／不确定性权重，全局场景结构暂时保留。不观察到的表面不能当已知自由空间，邻近表面也不等于应接触表面。此方案尚未实现／训练，不单靠扩散步数假设预测身体一定可靠。

## 7. 下一阶段与评估

顺序是源拟合 QA 和遮挡清单 → 补齐真实相机及前端 soft proposal → 小范围 query 可靠性改动 → 固定评估后训练。当前 native30 正式 validation 循环和配置尺度接口也还需接通；本轮未启动训练，长时间整个人消失后的补全继续排后。

优先比较相同前端输入下的 `前端原结果 → 无场景动作修复 → 加场景 → 加局部接触反馈`，区分时序先验、场景和反馈的增益；再比较共享 ego/exo 和独立训练，明确参数／数据／训练预算。主指标是遮挡关节或 vertex 的世界坐标误差，分强度／时长报告，同时看可见部位退化、root／heading、全身误差、抖动／滑脚、可判定接触／穿透、推理成本。不能仅报 PA 来掩盖世界坐标错误；局部平面代理不能当全场景 SDF。多样本固定 K 并报告预算，不能无说明把 best-of-K 与前端单次估计相比。

本轮代码与紧凑审计记录备份；恢复外参、曲线和图片留在本地，可重建。新增测试验证非周期播放边界和非零 root pivot 的外参恢复，不修改源数据或权重。
