# 场景通路保留结论与查询诊断

现有证据支持保留原结构的场景通路。场景仍主要通过条件特征进入 U-Net，同时还有 U-Net 之后的学习式接触/场景反馈。新增的主干 cross-attention 没有通过之前的增量比较，本轮没有重新训练，也没有改动保留模型、官方 41k/55k 或历史实验封存。

## 当前场景如何影响生成

1. 可见场景的体素编码产生全局摘要和 patch tokens。人体区域查询对这些 tokens 做 attention，再把聚合结果加到 U-Net 条件中；动态场景也有对应条件通路。
2. 第一次 U-Net 给出整段粗动作 proposal。围绕 proposal 的 67 个表面锚点查询局部表面，并为 22 个关节查询更宽的场景关系；编码结果作为局部条件进入第二次 U-Net。
3. 接触与对应关系的预测还会产生有幅度上限的根位置/关节旋转反馈。它属于学习式场景反馈，保留；另外的解析物理优化在本轮关闭。局部条件、BPS 和学习反馈带有 ᾱ² 门控。
4. DDIM 用这次预测更新整段状态，再进入下一次去噪。场景 on/off 比较测到的是整套场景条件和反馈的联合收益，不能单独归因于某个 attention 或第二次 U-Net。

所以，“场景通过条件注入”是对的，但并非只有一个条件向量，也并非全部效果都来自条件注入。

## 补上的直接证据

场景收益复核覆盖固定 VAL 的 43 条不同录制，每条一个 L192 窗口：RICH 27、TRUMANS 8、EgoBody 8；使用两个预先固定的 DDIM seed。对比同一个保留 control3000 的 scene-off/on，解析物理优化均关闭。下面是 World MPJPE，单位 mm：

| 数据集 | clean：关闭 → 开启 | noisy：关闭 → 开启 |
|---|---:|---:|
| RICH | 205.07 → 161.83 | 235.17 → 179.71 |
| TRUMANS | 120.21 → 84.18 | 159.00 → 104.79 |
| EgoBody | 158.37 → 140.71 | 165.81 → 145.69 |

六组的录制配对 95% bootstrap CI 均支持误差降低。RICH clean/noisy 分别 25/27、24/27 条录制改善。另留出的 confirmation 子集基本延续趋势；EgoBody noisy confirmation 仅 4 条录制，差值 CI 跨 0，不能宣称该子组已稳健有效。

明确代价：RICH noisy 到输入头部位置的误差从 7.575 增至 9.287 mm（+1.712 mm，CI 为正）。这说明全身改善仍可能牺牲部分软头部约束。全身误差与头部保持应一起报告。

这些是固定窗口 VAL 的条件消融，不是完整 VAL/TEST 或与外部方法的比较；scene-off 也不是另训的无场景模型。详细逐录制统计、CI、脚部代理指标和副作用见 [SCENE_EVIDENCE_zh.md](SCENE_EVIDENCE_zh.md)。

## 高噪声与时序查询：已完成的诊断

复用之前固定的 dev12（每集 4 条不同录制），各跑 clean/noisy：24 个预测、480 个去噪步骤、960 条 near/relation 查询统计。捕获实际查询中心和原查询结果，没有增加或替换几何查询。所有预测在运行时均与保留的原输出逐元素完全一致；输入、观测、参考、GT 和 rest 也一致。GT 仅在采样结束后用于误差统计。

以下是机会数加权描述均值；高噪声为 ᾱ<0.1，低噪声为 ᾱ≥0.9，不能把各去噪步当作独立样本：

| 诊断 | 高噪声 | 低噪声 |
|---|---:|---:|
| 中间 proposal 的关节误差 | 165.76 mm | 130.62 mm |
| 近邻选中表面点的相邻帧位移 | 26.60 mm | 14.72 mm |
| 近邻表面点位移减查询中心位移的模 | 35.83 mm | 20.86 mm |
| 关系最近点的同一残差 | 40.05 mm | 26.14 mm |
| 近邻选中槽无效比例 | 50.18% | 48.69% |
| 近邻有效选中槽中法向可靠比例 | 59.42% | 62.52% |
| 合并局部/关系 context 的相邻帧 RMS 变化 | 0.14796 | 0.06751 |

proposal 误差在三数据集的 clean/noisy 六组都随低噪声阶段降低；表面点变化也减小。与早期局部不稳定时压低其影响的现有 ᾱ² 门控方向一致，但这只是诊断，**没有证明该门控最优或新可靠性门控有效**。表面点变化还包含正常动作、表面采样与最近邻变化，不能叫接触切换率或滑步率；proposal 的脚速也不是最终输出的脚速。

记录范围严格限定为 near 的最大半径 0.6 m、rank0 槽和 relation 的 nearest rank0 槽；不代表全部 3×8 near 槽或 wide 向上关系的可靠率。context 是 near+relation 合并结果，包含无证据区域的置零及覆盖变化，不能称为 relation-only 的变化或纯特征抖动。

## 实际暴露的覆盖问题

dev12 的 EgoBody 四条录制中，near 选中槽无效比例约 97%–98%，而 RICH 约 36%–39%、TRUMANS 约 13%–14%。这是当前少量固定窗口上的实际覆盖稀疏现象，尚不能归因为坐标错误或某一种相机原因。

再查原 43 条录制的既有阶段日志（两个条件、seed0，对每个 anchor 在全部 3×8 槽取 any-valid 后统计覆盖）：EgoBody 的 near anchor 覆盖均值约 13.3%，relation region 覆盖约 77.6%；约 61.4% 的 region 仅有较宽关系证据、缺少 near 证据。这个均值与 dev4 不同，反映录制间覆盖差异很大。全局场景与宽关系仍可发挥作用，因此“近邻少”不等于“场景完全没用”。但不能假设模型随时能在每只脚下看见可靠地面，也不能凭覆盖日志解释其全部误差。

这给出了比再加 attention 更具体的后续检查方向：按可见证据量区分失败案例，核对近邻/宽关系的作用及未知区域处理。当前并没有做 GT 位置重新查询、单独切断 global/local/feedback 的因果消融，也未测完整 mesh 穿透。

## 五项细节的验证边界

| 细节 | 当前能确认 | 仍不能确认 |
|---|---|---|
| 区域 query 的语义 | 实际代码含区域身份、姿态/位置和观测置信信息 | 哪种 query 设计最好 |
| 全局与局部证据 | 实际存在独立编码与查询，联合场景收益已复核 | 各通路各自贡献及冗余 |
| 高噪声可靠性 | 补了真实 DDIM 查询与 proposal 的分阶段诊断 | 新门控优于现有 ᾱ² |
| 坐标、尺度、未知掩码 | 真实递归查询坐标流经审查；统计掩码测试与独立 FK 核对通过 | 全部数据/场景物理语义无误 |
| 时间连续性 | 补了真实相邻帧最近点/context 变化及有效分母 | 最近点变化是错误、或某项连续性改动有效 |

因此本轮结论是：**现有场景机制有可复现收益，足以保留；未获得更复杂融合结构胜出的证据。** 保留原结构 control 作为工程候选，官方 41k/55k 继续保留；不据本次查询诊断再启动长训。RICH 续训相对 41k 的约 1.52 mm 收益仍不显著，不能与约 49.35 mm 的同模型场景 on/off 收益混淆。

## 核验与复用

- [PLAN.json](PLAN.json)：固定窗口、种子、模型、原输出和显式源码依赖。
- [QUERY_SUMMARY.json](QUERY_SUMMARY.json)：分 ᾱ 的完整统计与分母。
- [CPU_RECHECK.json](CPU_RECHECK.json)：24 份原始 trace 的 CPU 重算。
- [QUERY_INDEPENDENT_AUDIT.json](QUERY_INDEPENDENT_AUDIT.json)：独立 NumPy 复算 14,400 项摘要、5,760 项比例，最大差 4.44e-16；独立 GT FK 最大差 5.49e-7 m。最终预测 bit-exact 是运行时守卫，CPU 审计不冒称重新推理。
- 复用模块：`ops.scene_query_review`，动作 `prepare/run/recheck`；统计模块 `ops.scene_query_metrics` 的 14 项测试通过。没有新增一次性 run 脚本或模型副本。
