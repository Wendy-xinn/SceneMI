# 时间尺度与头部约束实验（2026-10-09）

用户已授权直接尝试调整，并评估头部硬约束。此处开展一项配对1k续训及固定验证消融，不启动55k。

## 训练变量

orientation_v3从原55k初始化，保留v2全部目标，仅将累计转向损失乘以128帧参考平均累计时间平方与当前窗口平均累计时间平方之比。恒定角速度偏差下三种窗口强度一致，128帧与原v2严格相同。保留v1/v2行为。训练数据、采样、噪声、控制mask、场景dropout、优化器和学习率计划与旧1k试验保持相同。

训练日志training.log；进程training.pid；完整命令command.json。模型输出在orientation_v3。训练后自动运行evaluate_turn_balance.py，日志evaluation.log，状态evaluation_status.json。

## 头部约束消融

输入相机旋转和已知固定安装旋转用于求解头部关节15的局部旋转；不是直接覆盖全局骨盆或转动整个人。只有TRUMANS、RICH、EgoBody interactee的已知虚拟相机标定启用，实拍PV wearer保留软条件。投影不读取GT动作、GT接触或每窗GT标定；GT只用于离线误差检查。

比较v2、v3、v3生成结束后投影、v3每一步预测x0投影、v3仅在alpha≥0.8的低噪声阶段投影。当前只约束头部旋转，不通过移动根部来硬贴相机位置；后者可能把支撑脚抬起。现有采样器与模型接口默认行为不变，约束在独立实验包装器中启用。

旋转投影严格满足已知相机朝向，但不保证颈部关节角合理。头部误差变成零是约束的定义，不是泛化收益。重点检查身体转向幅度、骨盆朝向、脚部支撑、位置误差，以及头相对颈部旋转幅度。

## 固定评估

复用上一轮48条人物序列、144个128帧窗口、两组噪声，排除此前展示序列，v2预测须复现旧缓存。另加同一批人物中具备长窗口覆盖的24个64帧窗口、24个192帧窗口，采用最近有效起点。附加窗口是开发探针，总体汇总仍只用原144窗；它们不构成独立测试集。

7项新增/相关测试及26项朝向、步态、协调和原生人体回归测试已通过。缓存头部投影检查在144窗上确认：最终局部旋转投影不改变22关节FK位置，但显著增大部分域的颈部补偿，详见head_constraint_audit.json。
