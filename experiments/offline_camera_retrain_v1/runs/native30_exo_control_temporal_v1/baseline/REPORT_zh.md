# 修复时序参考后的 EXO 基线

64 条不同验证序列，clean/noisy 两种输入；以下为缺失关节 MPJPE，单位毫米，越小越好。每个数据集按序列等权，宏平均再对三个数据集等权。缺失关节不等同于真实遮挡。

| 数据集 | 输入条件 | 修复后的参考 | 原 41k | 41k + 3k control |
|---|---|---:|---:|---:|
| rich | clean | 40.61 | 65.24 | 62.19 |
| rich | noisy | 71.67 | 96.21 | 90.72 |
| trumans | clean | 162.43 | 214.86 | 215.70 |
| trumans | noisy | 190.98 | 276.39 | 269.84 |
| egobody | clean | 46.55 | 78.21 | 79.65 |
| egobody | noisy | 69.94 | 98.84 | 95.37 |
| macro | clean | 83.20 | 119.44 | 119.18 |
| macro | noisy | 110.86 | 157.15 | 151.98 |

结论：control 在 noisy 条件下比原 41k 有小幅改善，但两者的缺失关节误差都高于修复后的输入参考。因此，本对照不能证明直接使用 EGO 训练模型便已获得有效的 EXO 遮挡补全；后续适配必须同时超过 control 和输入参考。

输入来自 GT 构造的模拟 EXO 观测及噪声，且时序参考使用窗口内双向插值；不是实际单目估计器端到端输出，也不是因果在线实验。这里不使用 TEST，不作为论文正式测试成绩。

384 行结果已通过独立 CPU 指标重算及来源、配对检查。四处 6D 通道严格阈值差异另按物理量复核，最大关节差异 0.010214 mm、旋转差异 0.004475°；原失败证据保留在 recheck.log 和独立审计记录中。

详见 SUMMARY.json、rows.jsonl 与 CPU_RECHECK.json。
