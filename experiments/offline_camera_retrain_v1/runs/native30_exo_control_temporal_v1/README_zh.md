## 最终结果（2026-10-19）

1,000 次更新、8,000 个 EXO 训练窗口已完成，正式训练耗时 58 分 59 秒；最终验证、独立 CPU 复核及汇总于北京时间 16:01 完成。主干和优化器状态均有完整记录，最终只保留一个可恢复的 `training/last.pt`。

**EXO 有实质改善，但未通过全部预先登记的严格验收条件。** 下表为 64 条验证录制的未观测关节 MPJPE，单位毫米、越小越好；数据集内等录制平均，再对三个数据集等权。

| 输入条件 | 修复后输入参考 | 未适配 control | 最终适配 | 相对 control 改善 | 相对参考改善 |
|---|---:|---:|---:|---:|---:|
| 干净 | 83.195 | 119.182 | 79.746 | 33.09% | 4.15% |
| 带噪 | 110.865 | 151.978 | 98.474 | 35.20% | 11.18% |

可见关节宏平均误差由 control 的 9.812 / 37.240 mm 降至 4.117 / 25.459 mm（干净 / 带噪）。全身误差由 41.700 / 71.049 mm 降至 25.415 / 46.690 mm。三个 EGO 锚点的两种输入条件输出均逐值一致，原主干张量摘要保持不变；已登记的脚部工程保护门槛通过。

严格验收唯一未满足项是干净输入的未观测误差相对参考只改善 4.15%，没有达到预先规定的 5%。`ACCEPTANCE.json` 的 pass 是旧训练器针对 control 的门槛；整体判定以 `USABILITY_REVIEW.json` 的 `usability.status=failed` 为准，`STATUS.json` 已明确区分两者，原始实验审计记录未改。

局部限制仍然存在：

- EgoBody 干净输入的未观测误差由参考的 46.552 升至 47.728 mm；该指标只有 15/17 条录制存在有效缺失关节。相对参考，全部数据的未观测关节改善录制数为干净 31/62、带噪 44/64；不能说每条序列都获益。
- RICH 带噪输入的未观测误差为参考 71.670 → control 90.715 → 最终 58.223 mm；相对参考 19/27 条录制改善。干净输入为 40.608 → 62.194 → 39.349 mm，相对参考只有 12/27 条改善。
- 之前手腕抽搐的 EgoBody 案例（`recording_20220215_S21_S22_01_interactee_1901-4901_master_full`，起始 1984，相对 bundle 帧号）未解决旋转时序问题。左腕逐帧转角 P95 在干净输入下为参考 9.327 → control 13.529 → 最终 23.867°，带噪为 7.509 → 8.717 → 19.472°，GT 为 14.738°。手臂逐帧旋转误差也由 control 的 1.842 / 1.562° 升至 2.450 / 2.054°。转角 P95 本身不能单独证明抽搐，但这些结果不足以宣称时序问题解决。
- 相对 control，整体位置速度与加速度误差下降；相对输入参考，干净输入加速度误差反而约增加 18%。脚部保护门槛通过不代表无漂浮、滑步或 mesh 穿模。

每 100 步平均训练 loss 从 0.652 降至后半段的约 0.35–0.36，后半段趋于平台；只有起点和最终点验证，不能宣称充分收敛或延长训练必然有效。本轮为 EXO 内部适配训练，没有进行 EGO/EXO 主干混训。

模型和配对预测保留用于当前可视化检查与后续方案讨论，尚未替换正式模型，未自动追加实验。完整逐录制、可见/未观测、时序及有效分母结果见 [USABILITY_zh.md](USABILITY_zh.md) 和 [USABILITY_REVIEW.json](USABILITY_REVIEW.json)。所有结果均来自历史 VAL 和模拟 EXO 观测，不是 TEST 或实际单目估计器端到端结果。

## 实验协议

本轮按“先核对 control 的 EXO 能力，再训练 EXO 适配”的顺序执行。当前生成器是原 41k 模型继续训练 3k 得到的 control；3k 是独立阶段，不代表恢复原优化器到 44k。原 41k、55k 和 control 权重均保留。

## 对照与判断依据

- 基线：64 条不同验证序列，RICH 27、TRUMANS 20、EgoBody 17；每条使用 clean/noisy 两种 EXO 输入，比较修复后的输入参考、原 41k 和 control，共 384 行结果。
- 三者使用相同窗口、观测、缺失掩码与随机种子，分析物理引导关闭。缺失关节不一定都由真实物理遮挡造成。
- 初步结果显示，control 相比原 41k 在 noisy 输入下有一些改善，但其遮挡关节误差仍高于输入参考。仅凭“能够直接输入 EXO 并输出动作”，不能证明 EXO 补全有效。
- CPU/GPU 参考重建出现四处超过原 6D 通道逐元素容差的差异；独立诊断的最大关节差异为 0.010214 毫米、最大旋转差异为 0.004475 度。保留原失败记录，另做有明确物理容差的复核。

## 本次适配

冻结 control 的全部原参数，只更新内部 EXO LoRA；EGO 路径绕过适配参数。训练和验证均使用修复后的时序参考。保持原监督、TRAIN 标定系数和场景输入，关闭分析式物理修正。

固定训练 8,000 个 EXO 窗口：batch 8、1,000 次更新、50 次 warmup，学习率 1e-4，RICH/TRUMANS/EgoBody 采样权重为 50%/25%/25%。只保留一个完整可恢复的 `training/last.pt`，最终步验证，不根据本轮验证自动延训或挑选 checkpoint。

吞吐测试中，batch 2/4/8 分别约为 1.24/1.58/1.75 窗口每秒，batch 8 比 batch 2 高约 41%。这些测试更新已丢弃。CPU 参考与数据准备仍占较多时间，提高 batch 无法直接消除该瓶颈。

最终验证覆盖上述 64 条 EXO 序列和三条 EGO 锚点。`STUDY.json` 预先登记了判据：clean/noisy 两种条件下，遮挡关节的等数据集宏平均误差均需比未适配 control 和输入参考至少改善 5%，同时检查各数据集退化、可见关节保持、脚步指标和 EGO 输出完全一致。这里是开发验证集，不是 RICH TEST 指标或全新保留集上的泛化结论。
