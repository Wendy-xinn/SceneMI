# 冻结 EXO 适配模型：有场景 / 无场景配对验证

原参考下，三数据集等权全身 MPJPE：clean **22.33 → 21.80 mm（下降 2.37%）**，noisy **53.10 → 51.75 mm（下降 2.53%）**。总体小幅改善，TRUMANS clean 和 RICH noisy 的全身误差略有升高；EgoBody noisy 的缺失关节误差也升高，不能称所有数据集、所有条件均获益。

缺失关节 clean 的结论依赖聚合口径：等录制三集宏平均略降，但将全部缺失关节直接池化后 **146.03 → 148.64 mm**，反而升高。noisy 的缺失指标在两种口径下均降低。

三个数据集各 4 个不同录制的验证窗口，共 12 窗；每窗 192 帧、30 Hz、20 DDIM 步。冻结 EXO v2（适配 1000 步，基座 41k），不训练、不使用 TEST。原参考和修复参考均评估 clean/noisy：复用 48 个有场景输出，新算 48 个无场景输出，共 48 对。

无场景仅切换 use_scene=False，关闭全局/局部场景输入、场景反馈和物理场景引导；观测位置、置信度、缺失模式、相机、骨架尺度、参考、观测 IK/锚点、种子均保持一致。三个禁止调用 guard 全为 0。该结果衡量全部场景推理路径的合计作用，不能把差值全部归因于网络学习的场景表征，也不是无场景重训。
