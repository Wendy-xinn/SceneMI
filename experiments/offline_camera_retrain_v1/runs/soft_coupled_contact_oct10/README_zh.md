# 软朝向耦合与接触区域代理对照（10月10日）

三组从相同joint_all1000最终权重出发，各1000步、batch4、FP32、lr2e-5、warmup100、seed2026、orientation_v5、low_noise0.25、场景dropout0.1，均从第一步更新全部参数。原三数据集20Hz、动态场景、RICH官方验证划分、接触BCE及采样比例不变。

- baseline：原损失，仅延长相同训练预算。
- coupled：额外0.25×可用且可信度加权的软观测头部朝向损失，独立于扩散时间；0.25×头相对骨盆/胸/颈方向损失，以及0.01×4帧相对旋转变化监督，后两项乘alpha²。
- coupled_contact：前者加RICH有效正接触区域的FK关节位置(2×)、参考速度(.02×)、脚接触参考高度(4×)、低于参考2.5cm的单边惩罚(8×)，均乘alpha²。

接触项是**原生22关节区域几何代理**，不是mesh接触顶点或真实场景SDF/碰撞监督。接触标签只用于训练损失，不进入条件输入；运动接触匹配GT速度而不是强制静止，缺失标签损失为零。不会要求人体躯干始终与头部同向；相对转动的目标来自训练GT。没有硬投影，没有推理时使用GT。

完整关节轨迹来自GT模拟；部署需要估计轨迹或经过标定的相机转换。可信度是模拟元数据，尚未经过真实视频标定。此对照是软监督机制筛查，不能证明真实视频质量。

评估使用相同192窗口、两个种子、DDIM20，并检查干净、小漂移、漂移/缺失、仅位置、低可信度及无控制。按序列汇总各数据集、转身幅度、64/128/192长度，检查朝向、转身率、脚滑、悬空与穿透代理；预留48窗口在联合质量筛查通过后使用。
