# 软轨迹与身体转向联动短训（2026-10-09）

目标是减少反向/不足转身，同时不以脚滑、悬浮和颈部补偿换取头部朝向。后续输入来自视频估计，保留软控制；本轮不硬锁相机/头部。

## 两组配对训练

均从原55k开始，各1000步，batch=4、lr=2e-5、seed=2026、AdamW重新初始化、warmup=500、float32、scene dropout=0.1、低噪声采样占比0.25、原64/128/192窗口分布。训练期随机mask与此前一致。数据、动态场景、接触、身体原生协议及步态损失保持一致。

- noise_gate / orientation_v4：以v3时间归一化为基础，仅短时转速和累计转角的权重由alpha改为alpha²；绝对头部/骨盆/腿部朝向仍乘alpha。
- neck_parent / orientation_v5：在v4上增加0.25倍的GT全局颈部父节点（关节12）朝向损失，乘alpha²。目标来自训练GT，不是硬拟合输入相机。其梯度经过上身父链，不经过头部局部关节。

alpha为当前扩散时刻的累计干净信号比例。两组训练单独运行并记录sample_trace。尚未通过结果验收，不启动新55k。

## 评估协议

对照为此前v3的有效1k checkpoint。复用48条验证人物序列的144个128帧窗口，以及24个64帧、24个192帧开发探针；排除旧展示片段所属人物序列。每窗两组固定DDIM20噪声。v3的干净输入预测逐项核对上次缓存。

输入压力测试分为干净、平滑偏差、平滑偏差加0.5秒缺失：头部/相机条件位置x轴3–5cm偏移，y轴至多1cm，z轴0–2cm渐变，yaw平滑3–11度；只改trajectory的关节15槽及控制mask。GT、camera、occupancy、BPS都不改变。因此这不是端到端视频估计/场景重建误差评估，也不能据此推断置信度已经标定。另在32个窗口检查完全移除轨迹条件后的响应，避免把忽略条件误当鲁棒。

主要看W-MPJPE、PA-MPJPE、头/骨盆旋转误差、转向符号和不足率、脚滑、悬浮、双脚移动及头对颈部局部旋转。序列内平均、序列等权；四个数据/角色组各12条。配对区间按人物序列bootstrap，属于用于调参的开发诊断。
