# 冻结12600步模型：30窗均衡扩展VAL审阅

这轮评估已经完整结束：同一个12600步checkpoint、30个不同recording、每个数据集10窗，每窗clean/noisy各一次，共60/60次。`SUMMARY.json`为complete且is_final_complete=true；独立CPU复核为passed_complete，60份输出的身份、SHA、形状、有限性及全部指标重算通过，最大重算差异0；365个封存源码检查通过。

结论：模型已经能在不少片段恢复有用的动作，TRUMANS相对较好；但域间差异、复杂全身姿态和落脚稳定性仍明显不足。现有证据支持继续保留已授权的训练基线，同时优先定位RICH困难姿态与滑步问题；不能据此承诺55k一定达到旧模型水平。此次是一个checkpoint的横截面扩展评估，不能把30窗均值与之前3个fixed窗均值相减后称为训练提升。

以下为每个数据集10个recording等权平均。全窗均为192帧，因此MPJPE的等窗与有效计数加权均值相等；clean/noisy是同一窗口的配对输入，不是60个独立recording。

RICH的局部足误差即使去掉各自root平移、用各自root逆旋转后的身体坐标比较，仍约0.33m，说明问题不只是身体整体摆错位置；关节姿态和腿部恢复本身也需要改善。噪声平均使MPJPE上升，但个别旋转指标会下降，不应将单项反向变化读成抗噪问题已解决。

## 脚在GT低速时仍然移动

GT分层按预先规定的运动学量解释结果，不删样本：23窗root水平路径≥0.5m归为moving，3窗近静态，4窗mixed。moving包括转身、瑜伽、俯卧撑等身体移动，不等于23段标准行走。

下表仅针对23个moving窗口，在**相同的GT脚关节速度<0.2m/s时段**按有效样本数加权：

| 指标 | clean | noisy |
|---|---:|---:|
| GT脚本身速度(m/s) | 0.0607 | 0.0607 |
| 预测脚速度(m/s) | 0.3453 | 0.4110 |
| 预测脚仍超过0.2m/s的比例 | 61.4% | 71.4% |
| 身体局部足误差，等窗口均值(mm) | 230.2 | 237.7 |
| 足速度误差，池化RMSE(m/s) | 0.6825 | 0.7387 |
| 首末帧新增root水平误差，等窗口均值(m) | 0.129 | 0.134 |

分域的moving结果也一致暴露滑动：

| 数据集/moving窗数 | GT低速期GT足速(m/s) | 预测足速 clean/noisy(m/s) | 预测足速>0.2m/s clean/noisy |
|---|---:|---:|---:|
| TRUMANS / 7 | 0.0304 | 0.3272 / 0.4261 | 58.0% / 71.6% |
| EgoBody / 7 | 0.0773 | 0.2853 / 0.3499 | 53.0% / 66.5% |
| RICH / 9 | 0.0740 | 0.3996 / 0.4394 | 69.8% / 74.4% |

因此，不只是个别截图或静态窗口造成印象：较广覆盖下，应该慢下来的脚确实经常没有慢下来。它与“已经学到部分左右相对摆动”不矛盾；摆动幅度、切换大致顺序、准确落脚时机与世界坐标中脚保持住，是不同层次。近静态窗口也非完全稳定，GT速度约0.0154m/s时，预测仍约0.281/0.294m/s。

这里的低速掩码是GT运动学代理，不是真实接触标注；脚为原22关节骨架的10/11号关节，速度为原始30Hz三维差分，包含竖直运动。该比例不能写作contact头错误率、物理接触失败率或穿透率。

## 均值之外，失败尾部仍很明显

分位数是30个**窗口平均误差**的分位数，不是全部帧/关节的分位数，也不是置信区间。

| 范围 | MPJPE均值 clean/noisy(mm) | 窗口中位数 clean/noisy(mm) | 窗口P90 clean/noisy(mm) | 最差窗口 clean/noisy(mm) |

最差全身窗口是case27，RICH `Pavallion_018_sidebalancerun`：MPJPE为419.0/440.4mm，root全局旋转角误差72.2/69.3°，世界踝/足关节误差达1.147/1.148m。**clean头部被条件约束的关节误差仅0.00077mm**，所以不能将失败概括为“头部观测没有跟住”；头部位置几乎贴住输入，整个人的朝向和下肢仍然可能错得很大。这里72.2°来自完整SO(3)旋转角误差，不能当作单独yaw误差。

case21 `Pavallion_003_yoga1`也有308.6/309.7mm全身误差；局部脚误差最大的case28 `Pavallion_006_yoga1`为513.1/523.4mm。困难姿态是明确短板。EgoBody最差case18也有289.9/296.3mm，说明不能只修RICH后就宣称所有数据域稳定。

## 能据此决定什么

继续原基线有依据：当前并非整套网络完全失效，较广窗口中的TRUMANS表现相对较好，部分EgoBody窗口的误差相对较低。但“已经能稳定走、脚步正确、只是再多训一点”的说法缺乏支持。特别是RICH困难姿态、脚低速期滑动、局部腿姿态仍应作为后续主要验收项。

这30窗可以固定为后续里程碑的固定评估集合，用完全相同窗口/seed比较学习进展，而不是继续用不同集合的均值互相替代。现有单窗配对证据见[case6核实记录](CASE6_MATCHED_REVIEW.json)：12k→12600的TRUMANS同窗位置误差下降，但落脚足速增加、noisy朝向回退，进一步说明不能仅盯MPJPE。

每个数据集只有10个recording、每recording只有一个中位窗口，尚不能替代全量时段覆盖；该集合也属于已用于开发的VAL，不是未见TEST。最终穿地深度、真实支撑接触以及tracker闭环效果均未由本次测量。训练继续不代表保证55k结果。
