# 8000 步 EgoBody：地板覆盖与穿地复核

这张图的穿地是真实预测误差。输入见过远处地板，但目标脚下没有局部地板覆盖；当前物理引导开启，也没有提供完整场景的硬碰撞保证。

数据来自已保存的 **8000 步**交互 HTML 中原生 mesh 数组，未用已经覆盖 latest NPZ 的 9000 步预测替代。完整数值、原始验证 SHA 与来源见 [FLOOR_AUDIT.json](FLOOR_AUDIT.json)，示意见 [地板覆盖和穿透图](FLOOR_COVERAGE_AND_PENETRATION.png)。GT 扫描仅用于此次显示和测量，没有交给模型。

实际模型 surface cache 包含 8981 个静态点，其中 629 个符合扫描高度与上向法线的地板点，612 个法线可靠；这些地板点位于窗口 Z=1.97–3.70m。所有被检查的 GT/预测脚在水平 0.1、0.25、0.6、1.25m 内均没有输入地板点。这三帧当前可见地板采样点为 0、0、1，那个点也远离脚下。录制级静态记忆因此不等于完整场景地图。

GT 脚底与局部扫描地面大多只差 0–0.5cm，个别约低1.5cm，不能解释预测约27cm的穿地。预测骨盆高度与GT只差0.4–1.3cm，但从posed mesh回归关节估计，预测膝屈仅约17–26°，GT约71–106°：身体到了坐姿高度，下肢却没有弯到坐姿。这是生成姿态问题，不能只归因于没看见地板。

当前 config 和 effective_config 均保留物理引导 enabled=true、iterations=2。`native30_physical_guidance.py:48–75` 只从可靠已观测局部表面建立约束，要求距离<25cm、切向<9cm、contact概率>0.5；plane项另要求有向距离绝对值<6cm。脚下缺乏局部表面时，这种修正没有地板证据。即使有证据，也保护可信观测，并限制每次forward内根平移最多2cm；它不是对完整地面mesh或SDF做硬投影。6cm之外只关闭plane项，不能误称其余近接触距离力也必然关闭。

6次观测IK主要服务头部位置约束，不是足底接触IK。`native30_gait_supervision_v2.py:53–63` 的 `support_penetration` 实际比较脚关节与GT双脚最低关节Y，也是训练软监督，并非mesh-floor碰撞检测。

因此这是一个“坐姿预测错误 + 脚下缺少局部可见几何 + 现有物理修正未兜住”的明确失败例。此次仅检查并记录证据，未修改训练源码、配置、模型、checkpoint、缓存或进程。
