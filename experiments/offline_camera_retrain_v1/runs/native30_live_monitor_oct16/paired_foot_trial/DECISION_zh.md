# 脚步短训结果与决策

复核时间：2026-10-17 12:53（上海）。

**本次1000步实验不支持通过关闭训练中的独立物理修正来解决滑步或悬空；不采用该候选替换主线。** 主线继续原配置训练到55k。本记录没有启动新训练、切换EXO或修改主训练。

## 完成情况与比较口径

两臂均从同一个24,500步完整状态出发，到25,500步各更新1000次。初始模型/优化器/采样器/RNG一致，1000次实际输入及全局学习率逐步匹配，末态RNG/采样器一致，见[MATCHED_AUDIT.json](MATCHED_AUDIT.json)。仅独立物理修正开关不同，学习式场景通路、贴头、IK和监督保留。

14个预先声明的不同录制VAL窗口，12 RICH、1 TRUMANS、1 EgoBody；主评价统一关闭推理物理修正，另5个核心窗交叉开启。三个模型共114次预测全部完成，独立CPU复算通过。这里不是全RICH评价或官方TEST。

## RICH结果

下表按“control → 关闭训练物理修正”列出；两组均为25,500步，推理统一physics OFF，误差和脚速越低越好。

| 指标 | clean | noisy |
|---|---:|---:|
| World MPJPE / mm | 175.707 → 177.353 | 196.494 → 197.147 |
| GT低速期水平脚速 / m/s | 0.25174 → 0.25228 | 0.33178 → 0.33446 |
| GT低速期脚高绝对误差 / mm | 45.821 → 47.838 | 55.664 → 58.606 |
| 可见表面GT校准误差 / mm | 55.061 → 58.757 | 69.733 → 73.767 |
| GT连续低速段水平漂移 / mm | 104.342 → 107.698 | 144.274 → 148.075 |

候选的双足相对运动幅度增大，但stride误差也增大，不能把脚动得更多当作准确步态改善。稀疏锚点的离表面阈值代理在不同汇总方式和输入噪声下方向不一致；GT也有相应偏差，只有11/12个RICH窗口具有可靠表面，不能称作全mesh悬空率。GT校准表面误差在两种输入下均退化。

control的核心5窗推理重新开启物理修正后，水平脚速反而增加clean 0.03117、noisy 0.05605 m/s，脚高误差略降。这也不支持靠现有推理物理项消除滑步。

24,500步父模型到control的RICH脚高误差改善，但水平脚速与World误差没有同步改善。因此本实验既没有找到脚步修复，也不代表所有身体指标都无学习收益。它仅检验一个开关及1000步续训，不排除其他物理建模或更长预算的效果。

完整数据：[REPORT_zh.md](evaluation/REPORT_zh.md)、[SUMMARY.json](evaluation/SUMMARY.json)、[CPU_RECHECK_all.json](evaluation/CPU_RECHECK_all.json)。[Viser](http://localhost:8802/)提供TRUMANS走动、RICH椅子、EgoBody走动三个案例的parent/control/no_physics菜单，每例均可切clean/noisy。

## 主线现状与后续判断

主线原worker106162与supervisor106142持续运行，12:53约42,700步，IO重启0。完整千步段总loss 39k/40k/41k/42k为0.16041/0.16138/0.16068/0.16327，脚步loss为0.06728/0.06858/0.06928/0.07101。近期接近平台，不能继续描述为所有监督稳定下降。

固定同一RICH窗口clean/noisy平均World MPJPE：40k 141.46、41k 113.69、42k 159.27 mm。best.pt已保留41k，实际文件SHA与元数据一致。40–42k均值138.14 mm相对37–39k的151.79 mm有所改善，但相应水平脚速0.310相对0.306 m/s未改善。它是单固定窗口的临时best，不能称全RICH最优；15,100步全量RICH结果不能冒充当前权重结果，也不能据此宣布超过旧55k。

下一项值得独立对照的实现问题是[参考骨架的头部完整旋转继承](REFERENCE_PRIOR_REVIEW_zh.md)：头部俯仰/侧倾进入全身初始参考，可能加重下肢校正负担。审计证明该机制存在，但最终网络已能纠正很多，尚未证明它是最终失败原因。修改它会改变参考、残差目标和几何查询，必须另训对照，不能直接替换冻结模型参考后宣称成功。本次没有自动启动该实验。
