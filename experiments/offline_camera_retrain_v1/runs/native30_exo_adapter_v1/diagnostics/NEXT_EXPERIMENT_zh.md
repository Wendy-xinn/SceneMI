# EXO v2 最小实验建议（尚未运行）

本文只记录下一步方案，不代表已启动训练、已调整参数或已验证收益。当前先完成已准备的大规模验证；不增加 GPU 任务，不修改本轮封印源码。

## 当前证据能说明什么

本轮冻结 41k 基座、只训练 EXO 内部 adapter 的 1000 更新已经完成。EGO 在本轮保存的 clean/noisy 开发窗口中逐位保持原输出，基座权重摘要保持不变，最终单文件权重独立 CPU 加载通过。然而，本轮预登记开发门槛未通过：RICH 的隐藏关节和双足运动 RMS 误差存在退化。

开发面板只有 12 个窗口，其中 EXO 是三个数据集各 3 个、EGO 是各 1 个。RICH 的三个 EXO 窗口中，phonetalk 改善，yoga 和 wipingchairs 的隐藏关节退化。noisy 均值主要受 yoga 影响，clean 均值主要受 wipingchairs 影响；排除对应窗口后均值变化可以反号。因此，这个面板适合发现故障，不能支持泛化结论，也不足以反复挑选 checkpoint。

逐窗 CPU FK 证据见 [RICH_FAILURE_REVIEW.json](RICH_FAILURE_REVIEW.json)：根位置和根朝向改善以后，遮挡踝/脚仍可更差。yoga 的右膝可见，但右踝和右脚连续 57 帧同时缺失；wipingchairs 左右对应 66/81 帧。这里全部关节都没有旋转观测。现有 IK 只使用可见位置，当一个膝关节没有可见下游踝/脚时，其角度更新强度为零。增加相同 IK 的强度无法补出缺失的角度信息。双方使用相同 IK，故这些证据也不能证明“强 IK 导致退化”。

## 第一优先：只验证数据集比例

如果扩大后的 **EXO** 验证仍确认长遮挡下肢退化，最小 v2 只将 EXO corpus 配额改为：

| 采样组 | 建议概率 |
|---|---:|
| TRUMANS | 1/3 |
| EgoBody camera_wearer | 1/6 |
| EgoBody interactee | 1/6 |
| RICH | 1/3 |

这样在 2000 样本预算内，RICH 曝光约从 215 提高到 667，仍覆盖全部训练 recording。保留冻结基座、显式 EXO gate、rank16、所有损失、IK、物理修正、噪声、recording 轮换和训练预算。此阶段不同时修改隐藏损失权重、长遮挡增强或重力项。

这是检验“短阶段跨数据集覆盖失衡”的最低成本假设，不保证足以解决不可见小腿方向、动作分布或噪声鲁棒性。也不能只看 RICH 改善：TRUMANS、EgoBody 的可见/隐藏及脚步指标都要继续报告。

## 初始化和对照必须明确

**干净的单因素对照：** 从相同 41k 基座、相同 adapter 初值/随机种子重新做 1000 更新，仅修改上述配额，与已经保留的 v1 1000 更新作同预算比较。旧 v1 是现成对照，无需为了复现再训练它。

**也可以暖启动当前 1000 更新权重，作为尽快获得候选的工程路线。** 但“旧配额训练 1000”与“新配额累计训练 2000”同时改变了训练时长，不能将收益归因于采样。若要做采样因果判断，需要从同一个 v1 权重分叉，旧配额和新配额各继续同样 1000 更新；Adam、LR 时钟、随机种子策略和所有其他设置必须一致。没有同期 control 时，只能称为“再训练后的候选改善”。

现有 sealed `adapter_trial.py` 不能直接用改配置的 `--resume`：它检查完整 effective config、1000 更新预算及 sampler fingerprint，父模型工厂也明确要求裸 41k，随后才安装 adapter。需要另建并封印新 stage 的合法暖启动接口，严格加载现有完整 base+adapter 状态，核对 base 摘要和 adapter 规格，记录父文件 SHA、累计起点 1000 和本阶段预算。不能通过改原 run、放宽 resume 校验或自动续训实现。

## 如果采样仍不足，再单独检验长遮挡增强

第二个独立因素可以是 EXO 下肢连续缺失增强，例如预先固定：25% EXO TRAIN 窗口随机选一侧，仅将该侧 `(ankle, foot)` 两关节统一隐藏 1–3 秒；保留其余观测、原始 motion/GT 和全部动作。左右等概率，不按验证失败案例挑训练窗口。具体概率/时长是待验证的初值，不是已证实最优值。

应在 observation/reference 构造链内完成：清 availability/confidence 及相应坐标/旋转有效值，再重建 reference 和导数有效掩码；不改 GT、不把 GT 作为补齐输入。普通 clean/noisy 传感器误差分布仍分别保留。这个因素不能与第一轮采样配额同时首次加入，否则无法判断哪个改动起作用。

暂不新增固定地面高度、强行站直、恒定足高或抑制 root 高度的项。蹲下、坐下、楼梯、抬腿/瑜伽都是真实动作，已有基于 GT 的姿态/脚步监督可以保留它们。当前证据优先指向遮挡条件下的动作补全，而非缺少一个能安全推广到所有动作的“竖直/贴地”规则。

## 超出原 12 窗口的验证要求

1. 先完成已准备的大规模验证，并明确它是 EGO 还是 EXO。**扩大 EGO 验证可以核对 EGO 基线/保留性能，不能直接验证 EXO 的隐藏下肢。EXO 下一阶段也需要独立、更大的 EXO 验证面板。**
2. 旧 12 窗口作为已看过的回归/故障锚点单独报告，不作为泛化证据。新的 EXO 面板按 recording 划分、覆盖三个数据集，尽量一条 recording 一个窗口。抽样/分层和随机种子先锁定，不看候选预测再挑窗口。
3. 普通代表性面板之外，可以单列长遮挡压力面板：按输入 availability 定义踝+脚共同缺失时长，并覆盖低运动、走动和非直立动作。压力面板不能与代表性平均数混成一个总体指标。若用 GT 运动量做预登记分层，应对所有候选使用同一规则，不能按误差挑选。
4. 在完全相同的窗口、输入数组和噪声/DDIM 种子上，比较保留的 41k、全量微调 EXO specialist 和本轮 adapter。报告每 recording 的变化、胜负数量/分位数、等数据集汇总和隐藏下肢条件误差，避免只报按关节数加权的单一均值。
5. 若新 EXO VAL 用于调参/挑 checkpoint，须预先留出未参与选择的独立 recording 子集用于确认；最终 TEST 不参与这些决定。EGO gate/基座摘要/序列化输出一致性继续核验，不以改善 EXO 为由放宽 EGO 保护。
