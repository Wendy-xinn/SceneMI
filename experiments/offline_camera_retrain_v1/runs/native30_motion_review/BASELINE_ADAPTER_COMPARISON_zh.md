# 41k 与 EXO 适配 v2：同窗口配对比较

生成时间：2026-10-18T17:38:50.081418+08:00

结论：现有完整配对中 v2 的全身平均误差更低；RICH 新 20 窗口的缺失/不可用误差改善较小。固定开发集 RICH noisy 的缺失/不可用误差反而上升，不能声称三个数据集所有条件均改善。

“可见”指位置观测可用，“缺失/不可用”按 observation_meta 可用性划分，包括遮挡、视野外及观测失效，不等同于纯物理遮挡。

本报告只复用已保存输出，使用修复参考人体之前的冻结协议；没有新推理或训练。下列均为验证集，不是 RICH test 指标。
