## 3. 总 loss 是什么，各项在监督什么

总目标可分为四个已经乘过系数的可相加小计：

```text
L_total = L_body + L_gait + L_observation + L_scene
L_gait = gait_total + 0.5 × gait_raw_total
L_body = base.total − L_gait
```

训练日志的 `base.total` 已包含脚步项，不能把它再与 `L_gait` 相加。本报告所有小计已处理这一点。逐步重建总 loss 的最大绝对误差为 3.794302277e-07，属于浮点计算误差。各损失使用不同归一化、置信度与时间步门控，单凭数值大小不能判断哪个监督“强”或哪个误差已经足够小。

### 3.1 动作/姿态小计

该项学习扩散去噪后的动作、FK 位置、时序导数、全局朝向以及头身协调。当前 `native30_losses.py` 与训练封存 SHA 一致；启用 gait v2 后，基础项的公式为：

```text
L_body = 1 × x0 + 0.5 × raw_x0
       + 0.2 × 全局关节旋转误差 + 2 × FK关节位置误差
       + 0.025 × FK速度误差 + 0.0000125 × FK加速度误差
       + 1 × 头部FK位置误差 + 0.5 × raw FK一致性
       + 0.25 × 根朝向 + 0.5 × 头朝向 + 0.25 × 颈朝向
       + 0.1 × 头根相对朝向协调 + 0.02 × 相对转向速度
```

旧版基础脚速 `0.075 × foot_velocity` 和旧 planting `0.1 × planting` 已在 gait v2 分支被替换，不能再把日志中保留的这两个诊断原值加进总 loss。部分基础项未单独写入 trace；JSON 使用 `base.total − L_gait` 得到可准确相加的 body 小计，其基础项系数由训练封存源码核对。

### 3.2 脚步监督

以下系数分别作用于常规 FK 路和 raw FK 路，raw 路额外乘 **0.5**；例如真正的 stance 贡献为：

```text
0.1 × (gait_stance_velocity + 0.5 × gait_raw_stance_velocity)
```

| 项 | 系数 | 作用 |
| --- | --- | --- |
| `stance_velocity` | 0.1 | GT 支撑期的脚速度误差 |
| `swing_velocity` | 0.05 | GT 摆动期的脚速度误差 |
| `relative_position` | 1 | 脚相对身体的位置关系 |
| `stride_displacement` | 2 | 0.2/0.4 秒脚位移关系 |
| `coordination_amplitude` | 5 | 脚运动幅度 |
| `coordination_relation` | 0.05 | 脚运动协调关系 |
| `support_height` | 2 | GT 支撑期脚高误差 |
| `swing_height` | 0.5 | GT 摆动期脚高误差 |
| `support_envelope` | 4 | 双脚最低点相对 GT 最低点的误差 |
| `support_penetration` | 2 | 低于 GT 双脚最低高度的代理惩罚 |
| `phase_free_planting` | 0.1 | 有支撑时，较慢一只脚的超额速度 |
| `bilateral_stride` | 1 | 根坐标系中左右脚差的时序位移 |
| `bilateral_amplitude` | 5 | 根坐标系中左右脚差的运动幅度 |
| `bilateral_relation` | 0.05 | 根坐标系中左右脚的运动相关性 |

这些项跟随 GT 动作及其可靠性，不预设必须左右交替走路。支撑判定使用 GT 脚速度阈值 0.2 m/s；高度与 envelope 目标来自拟合 GT 脚，**不是由可见场景推断出的完整地板**。它们是训练监督，不能保证推理时每个脚点接触场景或全 mesh 不穿模。

## 6. 收敛判断与当前决策

1. **数值训练健康，55k 已完整结束。**没有日志缺口、非有限损失或异常退出的证据。
2. **训练目标接近平台，不能称所有监督已收敛。**末 5k 总 loss 降约 2.18%，但支撑脚速度改善约 0.11%，场景与下穿代理没有同步改善。
3. **固定验证不支持“越训越好”。**末 5 次验证平均比前 5 次更差，且未超过 41k；这是局部警示，不是全验证集最终结论。
4. **不直接延长同配置长训。**第7节已完成统一配对评估：55k有小幅水平脚速收益，全身、脚高与可见支撑误差未全面改善。下一阶段应针对支撑与姿态之间的关系做有控制的改动，不能仅靠增加步数等待问题消失。
5. **场景学习收益与末期收敛是两个问题。**此前15,100步的27条RICH录制同权重消融，在独立物理OFF下，学习式场景ON相对scene OFF的World误差降低clean 28.86/noisy 46.96mm。这是既有场景通路的推理证据，并非本次55k消融，也不证明整套方法优于旧55k或其他ego方法。[证据与比较口径](../../../ops/EVIDENCE_STATUS_zh.md)。
