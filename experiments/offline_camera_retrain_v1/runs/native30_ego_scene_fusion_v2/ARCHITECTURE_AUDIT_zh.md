# 独立实现与评估审计

2026-10-19，训练与评估实现分别由其他代理只读复核；未因审计修改已封印源码。

- 推理输入仍经过原 model_inputs 白名单。新增分支只读取已有全局 token、region context 与 detached proposal，不引入 GT 查询中心、GT 姿态或新的隐藏关节观测。
- 真实 TRAIN GPU 预检中，开/关场景两种情况下新旧模型输出均 torch.equal，最大差为零；新输出投影梯度非零，原参数梯度尺度一致。见 PREFLIGHT.json。
- 两臂各两步后，315 个原参数张量均发生更新，新分支 26 个参数张量均发生更新；样本、参考、监督、几何输入、噪声、dropout 和开始/结束 RNG 完全一致，Adam 与固定 LR 日程复核通过。几何输入相同不要求两个已更新模型的预测查询位置相同。见 UPDATE_SANITY_2.json。参数发生更新本身不证明验证收益。
- 新评估入口固定阶段 checkpoint 的硬链接和独立模型清单。实际 CPU 测试确认：原训练路径原子替换、输入 registry 改动均不改变旧阶段的封印；原 41k 未改。见 evaluation_prepare_check/CPU_PREPARE_PIN_CHECK.json。
- 两个预先指定 DDIM 种子使用同一份 clean/noisy 观测输入。最终统计先在每个录制内平均两个采样种子与两种观测，再对 27 个独立 RICH 录制做 10,000 次配对 bootstrap，不将 108 次预测当独立样本。它们是采样种子，不是独立训练重复。
- 采纳条件同时比较同预算原结构 control 和原 41k，包含两种观测各自改善及脚步、加速度和头部保护门槛。无写文件的合成审计确认：2% 姿态改善可通过核心判断，0.5% 改善、noisy 退化、头误差多 1.01 mm、足高误差多 5.01 mm 均被拒绝。

边界：足速是在 GT 脚关节三维速度低于 0.2 m/s 的相邻帧间隔上，统计预测水平关节速度；足高是全帧预测脚关节对 GT 的 Y 误差。二者都不是完整 mesh 对场景的穿模率。最终须报告有效录制数和脚关节时间间隔分母，两个采样种子不重复增加 GT 机会数。验证采用每录制一个窗口，不是全部 RICH 窗口，也不是 TEST。43 个录制中有 12 个开发录制、31 个本轮留出录制，不能将全部 43 个称为未触碰的留出集。单次配对训练不能证明跨训练种子的普遍收益。
