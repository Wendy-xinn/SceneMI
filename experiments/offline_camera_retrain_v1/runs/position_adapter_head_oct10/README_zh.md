# 独立的位置输入条件支路

以1000步joint_all为基模型，冻结全部原模型参数，仅更新复制的稀疏条件编码器。输入头部位置有效且朝向缺失时逐帧切换支路；完整输入、同时缺失位置与朝向、关闭控制均使用原编码器。没有头部硬约束、姿态投影或新增观测损失。

1000步、batch4、FP32、学习率2e-5、warmup100、seed2026、orientation_v5、场景dropout0.1。训练固定仅头部位置控制；完整输入的基模型不更新。三数据集、20Hz、动态场景和RICH接触监督沿用当前版本。训练期使用GT模拟关节轨迹，部署需提供真实观测或经过标定的相机转换。

保存间隔250，每次保存校验完整基模型SHA256。最终使用last1000步评估，不按单步去噪验证选模型。评估与之前相同192窗口、两个种子、DDIM20：完整输入及仅位置各384次，两个模型合计1536预测；逐元素验证完整输入一致，再共同检查朝向、脚滑、悬空及穿透代理指标。

完整输入不退化只是兼容性保证，不代表现有转身误差已经修复。结果尚未完成时，不应启动新55k训练。
