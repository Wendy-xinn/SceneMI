# 从原55k独立训练的累计转向/转动尖峰修复

继前两组从55k直接开始的对照，生成回放改善脚步但906仍走错绕转方向且根部峰值28°/帧。此组再次从原55k加载，未加载回放候选；同样600步、batch2、样本/时刻/噪声/回放计划。只额外加入head/root累计方向路径在所有噪声下的监督和top10%旋转速率误差/超速尾部监督。训练GT只作目标，未作为推理输入。

与前组回放600步比较是消融对照，不是串联微调。标准DDIM以及原55k输出末端一次修正分别评估；复用同一最终权重。预登记门槛沿用，850/906脚滑与支撑及48条固定开发窗口都检查。只有一个eval-only最终权重，无optimizer/编号副本。
