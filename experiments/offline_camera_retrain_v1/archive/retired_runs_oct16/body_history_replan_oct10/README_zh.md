# 身体历史与状态反馈短训（2026-10-10）

## 目标与接口

支持“生成短时动作 → 仿真器跟踪 → 接收实际已执行状态 → 重新生成”的条件接口。重新规划使用实际状态历史，不把失败的未执行计划当成真实姿态。当前实现 native_history_from_world / attach_executed_history：骨盆世界位置、原生22关节旋转、实际body rest/model/scale、当前相机原点及world-to-anchor变换 → 与窗口一致的201维状态 → FK关节与全局旋转历史。

接口不读取未来GT、接触标签或GT拟合的坐标变换。已有仿真骨架若轴向、零姿态或关节顺序不同，必须先完成native22映射；代码不是任意机器人的自动重定向器。这里没有接入实际仿真跟踪器，也没有测量真实tracking成功率。

建议闭环以过去0.8秒（16帧、20Hz）状态为条件，生成短预测，仅执行前0.2–0.5秒并滚动更新；跟踪失败提前中断，用新实际状态重规划，场景动态物体也更新到当前时间。执行段长是后续仿真方案，尚未实验验证。状态历史可隐含速度，但当前接口未单独编码qdot、力矩、接触力或仿真器执行能力；严重失稳不能只靠换历史保证恢复。

未来头部轨迹如果来自完整视频，可以提供估计轨迹和置信度；在线未来不可观测时必须mask，不能用未来GT。当前短训仍以完整头部轨迹为主，“history_only_forecast”专门隐藏未来头部，作为信息缺失压力测试，不能把离线重建成绩称为在线规划能力。

## 配对实验

三个各500步的对照：baseline、delta（局部头部增量/重力）、delta_history（再加入身体历史）。同一个joint_all1000 warm start、seed2026、batch4、lr2e-5、原生20Hz、原时长采样；orientation_v5损失保持一致，所有组的监督和接触BCE都排除前16帧，只评估之后的预测。

新增头部增量编码支路的输出层零初始化，已验证旧模型映射最大差0。历史以软条件接入已有typed22关节编码，不进行头部硬投影，不把历史硬写进扩散状态。

身体历史训练：50%准确过去状态，40%连贯3cm平移/8°root yaw/3°局部姿态误差，10%10cm/20°/6°误差；均由原生旋转及FK生成，扰动不破坏骨架长度，独立确定性种子不改变采样/扩散RNG。它是合成执行误差，不是仿真分布或真实可达性保证。

开发面板48窗口（TRUMANS16、EgoBody两个角色各8、RICH16），两个种子、DDIM20；未动额外48窗口确认面板。分别测试无历史、准确过去历史、轻度执行误差、较大执行误差、上一轮生成前缀、没有未来头部的历史条件。相同条件baseline/delta不会读取历史，可复用相同预测，避免冗余计算/动作副本。指标分别统计未来112帧及开头32预测帧；生成前缀反馈不等于真实滚动仿真，后续仍需连续序列实际状态验收。

## 场景距离目前是什么

当前occupancy是已观察场景的占据网格；逐帧BPS是**相机周围67个固定探针**到最近已观察表面的向量，而非22个真实关节到物体的距离。探针世界位置由相机位姿和固定相机局部锚点得到，静态表面来自因果历史，动态表面只用当前帧观测，不补全未观察物体。

BPS编码为delta / max(norm(delta),1m) / 2：1米内保留距离尺度，1米外饱和为方向向量；无观测有显式valid mask。它能表达粗略身体周边环境，但不随当前生成的身体姿态移动，不等价于脚掌/臀部到表面的接触几何。模型学到占据/BPS关系，不保证关节或mesh无碰撞。

当前接触预测是RICH22区域标签的辅助头，GT标签只用于loss，正式模型不把标签当输入；最近一次新增接触loss还是FK关节位置/速度/高度代理。尚无原生mesh接触点到真实场景表面距离/SDF的完整监督和采样引导。

后续建议显式加入当前生成x0的FK关节/mesh区域与**同一时刻**可观测物体表面的距离、相对向量和法线：带可见性/未知mask，不能用GT身体查询距离作为部署条件，不能直接查询高噪声扩散坐标并当可信几何；缺少闭合mesh/SDF时，最近表面距离也不能当“内部/外部”签名碰撞判定。身体历史这一轮保持场景编码不变，便于单独归因。

## 存储与验证

每组只原子覆盖一个last.pt，无best或编号checkpoint；评估只保存身份/指标/权重指纹，不复制动作缓存。已通过：零初始化旧模型一致性、局部增量平移不变、无观测特征清零、历史忽略不可信直接joint通道并重做FK、非恒等世界坐标变换、未来GT变更不影响预测。见condition_tests.json；配对采样、loss与模型指纹由评估结束时检查。

训练启动前磁盘可用105GiB。正式55k和旧当前控制warm start保持可恢复；新试验结束后按结果保留必要模型，去除不再续训的优化器并核验模型张量。
