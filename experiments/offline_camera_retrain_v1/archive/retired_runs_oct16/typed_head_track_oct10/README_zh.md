# 头部观测语义与可靠性配对短训（2026-10-10）

四组各500步、相同55k初始权重、相同数据/扩散噪声/场景及控制抽样，orientation_v5损失。camera_control保持相机条件；joint_clean换成真实头部关节；joint_noise增加平滑偏差、漂移、短缺失及仅位置观测；joint_reliable另提供模拟可信度并增加小权重的头部软约束。500步仅用于方案筛选，不证明已收敛。

新增位置/旋转独立可用mask、可信度和观测类型，旧权重明确映射到14维输入，新列零初始化。保持已审计数据管线、原场景缓存与GT动作监督不变。每250步原子保存；长训尚未启动。

camera_to_head提供已知刚性安装标定的相机→关节转换，旋转与平移按每帧头部旋转转换，位置单位米/2。无安装标定的真人PV不能当成已知转换。joint组使用GT头部构造训练与理想观测评估，不能报告为真实视频推理；噪声条件的可信度来自模拟器，实际估计器需要另外校准。场景使用干净相机缓存，本轮不代表带噪声重建的整条链路。

比较转身方向/角度、世界与PA误差、脚滑/悬浮、颈/胸补偿及噪声敏感性；若仍无稳定改善，不扩大硬约束、不启动55k。

两组独立进程并发（最多2组），各自独立RNG和日志；parallel_worker.py保留已启动的camera_control进程，再按空闲位置启动其余组。评估worker仅在四组全部完成后启动。

四组500步及7936次预测已完成。当前无候选通过联合验收，见[结果](RESULTS_zh.md)、[验收结论](ASSESSMENT_zh.md)与[下一轮方案](NEXT_zh.md)。
