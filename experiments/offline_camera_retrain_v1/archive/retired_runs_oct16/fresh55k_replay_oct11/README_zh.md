# 从原55k重新开始的生成轨迹回放对照

两组均直接加载正式55k，未加载之前600/400步失败候选。相同转向、native足底、头/颈旋转和连续支撑位移监督；control是标准GT加噪训练，replay在50%低噪声批次以冻结55k从纯噪声生成的训练动作作为加噪基底。其余50%仍标准扩散训练。回放只用train已知相机/场景/身体模板；训练GT只作目标，不是生成条件。

不继承失败候选的转向教师，不冻结原55k的错误世界足部位置。仅保持脚速度幅度，转向/落脚均由训练目标监督。没有硬头部投影或GT初始化。固定128帧训练，不引入GT身体历史或滚动初始化。

600步/组、batch2；原55k为独立基准，候选同评估种子。验收标准预登记，850和906脚步/支撑及更广面板都要过关，结果不满足不替换。每组仅一份evaluation-only权重，无优化器副本。完成后生成报告。

追加探索：在标准加噪组850/906预览后、所有terminal评分及回放组最终评分前，登记原55k DDIM20输出再过候选t0一次的输入分布一致性对照。复用两组权重，不新增checkpoint。它不是最初完全预登记的主比较，单独记录探索来源。
