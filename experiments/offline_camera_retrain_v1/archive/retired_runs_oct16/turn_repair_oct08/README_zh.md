# 朝向修复与配对短训（2026-10-08）

> 三组1k短训均完成，第二版改善转向但支撑退化，结论见[RESULTS_zh.md](RESULTS_zh.md)。

本轮处理相机/头部关系、全局朝向监督、带方向的转身监督，并进行短训；不启动独立无场景训练。最终状态以status.json和RESULTS_zh.md为准。

- 不改变数据、场景、网络结构或条件输入；没有把GT头部旋转额外注入模型。
- 两个试验从同一55k的last.pt初始化，重建AdamW，seed2026、lr2e-5、各1000步；其他设置沿用55k。control为coordination_v1，orientation为orientation_v1，唯一设置差异为损失profile。
- orientation_v1在原损失上加入全局head/pelvis/腿部SO(3)旋转误差，以及1/4/8帧间隔的带方向相对旋转增量误差。使用平方弦距离避免acos在0/π的梯度问题；按扩散clean-signal alpha加权。全局head/pelvis/腿部权重0.5/0.25/0.1，转速项0.02；增量按20Hz与各lag归一化。
- 两个试验都保留10%整批场景关闭、原接触监督和支撑监督。仅改训练监督；DDIM采样没有GT修正、投影或硬锁头部。
- objective_sha256单独记录监督代码指纹；source_hash继续保持原数据协议指纹。新loss使用init-from明确开展试验，不用resume改变已有训练。

## 验证

1. 26项朝向/步态/协调/原生人体/接触回归测试通过；包含相同姿态零损失、反向转身非零损失、有限梯度、角度跨±π连续性与无信号屏蔽。
2. 原55k的850/906/607/3487失败案例按原full-validation整批16个样本及batch_seed重新生成，与保存动作数组逐值一致。两个新checkpoint也按原批次及噪声比较，防止改变batch维度随机数流。
3. 另取固定seed919每数据组4个窗口，共16个，独立于展示失败例；报告位置误差、头/骨盆旋转误差、时间稳定性与支撑高度。样本少，不能替代正式全量验证。
4. 相机-头部关系抽查每组4窗口：虚拟相机关系稳定；实拍PV与拟合头部不适合统一硬设相等。训练使用原生人体GT全局旋转作为监督，不从验证GT估计校准并修改条件。
5. 转角按全局+Z在水平面的投影展开，仅作为描述；主诊断用SO(3)误差。转向符号一致率只统计GT单帧转角>0.5°，不能代替几何/生物力学验收。

启动监督进程已脱离会话；control_training.log、orientation_training.log和各turn_evaluation/metrics.json记录过程与结果。是否继续训练、调整监督或进行场景替换实验，等本轮结果确定。

## 第一轮结果与第二次调整

原orientation_v1 1k降低头部误差，但850/906仍在后半段快速反向旋转；腿部最大单帧全局旋转约41°/37°。因此没有将v1视作修复完成，也未开始独立无场景或场景替换实验。

orientation_v2仍从原55k初始化、同样训练1000步，保留所有输入和其他超参。新增水平朝向相邻帧atan2增量的累计轨迹误差（权重0.2）；这能区分通往相同末端旋转的长左转和短右转。GT头部/骨盆+Z水平投影范数>0.3时才统计增量；不比较原始Euler角，不硬设头部等于相机。已有相对旋转速率项权重由0.02增至0.1。该项仍按clean-signal alpha加权。新增整圈旋转路径非零损失/有限梯度测试通过。

原v1、control与55k预测及指标全部保留；比较图turn_comparison.png记录了v1仍然反向旋转的证据。待v2结果再决定后续训练。

新增监督代码指纹也用于resume检查；监督代码改变时必须使用init-from明确开展新试验。旧checkpoint缺少该字段时仍兼容原协议。
