# 温和头部条件与分阶段适配（2026-10-10）

四组各1000步，同一原55k起点、batch4、lr2e-5、seed2026、FP32、orientation_v5、scene_dropout0.1和low_noise_fraction0.25，原生三数据集与20Hz场景处理保持原审计版本。

- joint_all：全模型从第1步适配，完整头部关节输入。
- joint_staged：前200步仅训练稀疏条件编码器，后800步联合适配，完整头部关节输入。
- rotation_only：同joint_staged，仅20%的模拟头部轨迹去掉朝向，位置不变，不加漂移/缺失段。
- mild_only：同joint_staged，仅20%的模拟头部轨迹加入平滑漂移，位置误差范数不超过1cm、yaw不超过3°；不去掉旋转、不插入缺失段。

20%是五步配额，batch4每五步20条中恰好4条；在原随机关节控制mask之前计数。训练可信度全为1，不增加新头部损失或硬约束。joint_staged→rotation_only/mild_only可分别衡量单个增广；joint_all→joint_staged衡量分阶段策略（其全模型更新步数分别1000/800，不是相同联合更新预算）。

编码器warmup100步；其余参数从各自解冻时刻warmup100步，共用总1000步的cosine与0.1下限，给新编码器完整warmup后的适配时间。每250步原子保存，检查点存独立观测RNG与完整优化器状态，resume严格核对阶段与schedule。

每步追踪数据身份、扩散输入hash、timestep、控制mask hash及scene开关，验证配对不仅相同数据。预设固定192窗口、2噪声、DDIM20；核心144个128帧、补充64/192帧各24窗口。额外增加1cm/3°的温和测试条件，同时保留上轮更强漂移与缺失压力测试。

所有joint输入仍是训练GT构造的理想解剖关节观测；实际视频性能、未知真人相机安装关系和估计器可信度均未验证。场景缓存保持干净，本轮不是联合带噪声场景重建。尚未启动正式55k。

额外48个窗口已按种子2026101017预留：16条人物轨迹、14个录制/序列单元；EgoBody排除此前开发录制，RICH保持官方val（场景/人物可能与训练重叠）。不按任何预测误差选例，只有出现联合指标可接受的候选后再启用，不能称为未使用过的独立test。
