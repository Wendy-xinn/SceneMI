# 已知未来条件下的身体历史衔接试验

在线重规划可以使用已知的未来头部目标、已知静态场景，以及有来源的逐时刻动态物体预测。本轮完整保留未来头部和场景条件；不将“无未来条件”作为主要训练任务，也不对未来头部施加强制投影。

静态记忆覆盖以后经过的位置，和提前获得未来观测是两个不同概念。已有观测或已知地图可用于未来查询；记忆不会自动知道尚未观察的表面、物体未来运动。现有验证数据提供的是录制中的逐时刻场景观测，本轮属于已知未来场景条件评估，不代表在线物体预测已经完成。

## 两个受控训练分支

共同从 `body_history_replan_oct10/delta_history/last.pt` 开始，各续训500步。两者都使用原有身体历史和头部增量模型，扩散输入的前16帧改为对应噪声水平下的已执行身体状态，和采样时的已执行前缀保持一致。

- `matched`：只匹配已执行前缀的训练分布，保留原有未来损失。
- `boundary`：再加预测开头4帧的FK位移、根位移和跨边界速度损失。辅助目标是实际历史最后状态加GT相对未来位移；高噪声按alpha²降低权重。普通未来监督仍然保留GT。本项不保证动态可行性，受扰动的身体历史也不是仿真器输出。

共同设置：20Hz；历史16帧=0.8秒；训练窗口64/128/192；batch4；lr2e-5；warmup100；seed2026；FP32；低噪声采样25%；scene dropout10%；按时长平方根采样；native SMPL/SMPL-X共享22关节；RICH区域接触BCE权重0.1；头部输入使用GT解剖关节模拟，尚不代表实际视频估计误差。

开发集沿用48个窗口、18条身体序列，两个DDIM20随机种子；预测长度112帧，另计开头32帧。比较干净历史、轻度执行偏差、较大执行偏差；完整保留已知未来头部和逐时刻场景。上一轮相同条件/种子的前缀采样作为参考。`boundary-matched` 才是隔离衔接损失的对比；相对上一轮的变化同时包含新增500步训练的影响。预留holdout不参与本轮开发筛选。

## 场景与动态物体

`scene_memory_audit.json` 是本轮只读重查：904个有效场景bundle、780份记忆，全部静态记忆从原始owner=0观测独立重建；2712个首/中/末帧BPS查询只使用截至该时间的静态记忆及当前动态owner1..99。BPS重算误差为0。另测移动、消失和未来姿态修改不留下残影。检查依赖原始渲染owner标签正确，不等于检查了每个缓存帧或所有资产语义。

新增 `planner_scene_features.known_scene_bps` 是可选部署侧接口，尚未替换训练缓存：可查询已知静态地图和明确提供的逐时刻未来动态几何。录制静态记忆提供首次观测时间和当前决策时间，接口排除决策后才获得的静态观测；未提供的动态未来不会冻结为最后姿态，也不会把历史动态点写入地图。动态未知不等于自由空间，现有BPS有效mask也不等于完整物体不确定性建模。

## 保留策略

每个训练分支仅原子覆盖一个 `last.pt`，没有best或编号副本，不保存新的动作数组缓存。完成评估后依据结果保留有用候选；被淘汰分支剥离optimizer并逐张量核对模型未变。官方55k及当前有效起点保留。代码与小型结果备份到用户GitHub，权重和数据只留本地。
